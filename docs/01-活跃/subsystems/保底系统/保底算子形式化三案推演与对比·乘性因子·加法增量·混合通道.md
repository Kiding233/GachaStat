# 保底算子形式化：三案推演与对比

> 日期：2026-10-06 | 性质：形式化选型分析（**不改 P64 计划文件**，结论供裁决）
> 起因：`transfer_factors` 的 `(pA + amount)/pA` 在 `pA = 0` 时发散。P64 §3.1.5.6 已登记该边界，
> 2026-10-06 实测确认**可达**且有**两条语义相反**的来源（§3.1.5.6.1）。
> 本文从数学结构出发推演三个候选形式化，并给出对比与推荐。

---

## 0. 判据与起点

### 0.1 问题的一句话形式

一次抽卡有 n 个互斥结果，分布活在单纯形上：

```
Δⁿ⁻¹ = { p ∈ Rⁿ : pᵢ ≥ 0, Σᵢ pᵢ = 1 }
```

「保底」是一次概率操作，即单纯形上的一个映射。要定的不是「有哪些操作」，而是
**用哪个表示（representation）把这个映射参数化**。三个候选给出三个表示。

### 0.2 数学起点：单纯形上存在两种对偶仿射结构

单纯形不只是「一堆概率」，它带两种**互为对偶**的仿射联络（Amari 信息几何的标准事实）：

| 结构 | 坐标 | 测地线 | 平移群 |
|------|------|--------|--------|
| **m-联络**（混合） | `p` 本身 | `p` 坐标下的直线 | `p ↦ p + δ`（加法） |
| **e-联络**（指数） | `log p` | `log p` 坐标下的直线 | `p ↦ p ⊙ m` 再归一化（乘法） |

两条关键推论：

1. **「乘法 vs 加法」这个选择，本质是「把哪一条联络设为原生」**。不是实现口味问题。
2. **转移族天然是 m-仿射的**。「从 Q 搬 t 的质量到 A」在 `p` 坐标下就是直线运动
   `p ↦ p + t(u_A − u_Q)`，其中 `u_A` / `u_Q` 是 A / Q 上的单位分布（形状）。
   而 e-坐标下要写成 `m = 1 + δ/p`，**这个除法正是 ×0 问题的唯一来源**。

### 0.3 由起点导出的三条判据

| # | 判据 | 为什么它由结构决定 |
|---|------|------------------|
| **J1 全域性** | 算子在单纯形上是否处处有定义 | m-仿射的平移 `p + δ` 天然全域；e-仿射的 `m ⊙ p` 在 `p = 0` 处**永远**乘不出东西 |
| **J2 支持可增长性** | 能否把质量搬到零概率结果上 | 同上：`m·0 = 0` 恒成立，故乘性算子的**支撑是不变量**（只能缩不能长） |
| **J3 与现有语义的一致域** | 在 P64 定理 1 的不变式域内是否与现行规则逐点相同 | 定理 1 的证明以「组内比例 = 基础权重比例」为前提，故该域是设计自己划定的适用范围 |

补三条工程判据：**J4 参数约束是类型级还是值依赖**、**J5 复合律在参数空间上是什么运算**、
**J6 是否需要求解器**。

## 1. 参照系：甲案（现状，乘性因子）

### 1.1 推演

```
Φ_m(p) = (m ⊙ p) / ⟨m, p⟩,      m ∈ Rⁿ, m ≥ 0
```

转移族的写法（`transfer_factors`）：

```
A 内每卡  m = (p(A) + t) / p(A)
Q 内每卡  m = (p(Q) − t) / p(Q)
其余      不写（m = 1）
```

配平：`⟨m, p⟩ = (p(A)+t) + (p(Q)−t) + p(其余) = 1`，故归一化退化为恒等。

### 1.2 性质

| 判据 | 甲案 |
|------|------|
| J1 全域性 | **否**。`p(A) = 0` 或 `p(Q) = 0` 时发散 |
| J2 支持增长 | **否**。`supp(Φ_m(p)) = supp(p) ∩ {m > 0}`，支撑只能缩 |
| J3 一致域 | 自身 |
| J4 参数约束 | **类型级**：`m ≥ 0` 与 `p` 无关，手写 Modifier 不可能产出负概率 |
| J5 复合律 | 参数空间上 `⊙`（交换幺半群，单位 `m = 1`） |
| J6 求解器 | 不需要 |

**J4 是甲案唯一的真实优势**，且它是「参数级」而非「值依赖」的，这一点值得记账。

### 1.3 两处失效（2026-10-06 实测）

| 来源 | 目标组质量为 0 的原因 | 甲案行为 | 对不对 |
|------|-------------------|---------|-------|
| **一** | 池子声明该稀有度不可获得（`probability = 0`） | 不转移 | **对**（抬起来与池子的声明冲突） |
| **二** | 被另一条保底清零（`hard(ssr) → hard(r)` 之后） | 不转移 | **错**（`soft` 本就该把它抬起来，现被静默吃掉） |

**甲案分不清两者。** 而 J2 给出了根因的一句话表述：

> 来源二要的是**创造支撑**（把 SR 从 0 抬起来）。乘性算子的支撑是不变量，**按结构就做不到**。
> 这不是实现的数值 bug，是形式化的性质。

顺带两条实测事实（供权衡「值不值得换」）：

1. §3.1.5.1 的「性质 1（对数坐标 / 指数族）」**全文档只出现一次**（它自己的定义），从未被后续用到。
   那条数学理由没有兑现。
2. §3.1.5.2.1 声明本族配平（`⟨m,p⟩ ≡ 1`，实测六组差 0），故「框架统一归一化」那次除法
   **对当前唯一的族退化为恒等**。乘性机器从未真正跑过。

## 2. 乙案：加法增量

### 2.1 推演

```
Ψ_δ(p) = (p + δ) / Σ(p + δ),      δ ∈ Rⁿ
```

转移族要求 `Σδ = 0`，此时 `Σ(p+δ) = 1`，归一化同样退化为恒等（与甲案对称）。

由 §0.2 的推论 2，转移就是

```
p ↦ p + t (u_A − u_Q)
```

即**沿一条 m-测地线的平移**，参数是标量 `t`。于是 `δ = t(u_A − u_Q)`，`Σδ = 0` 自动成立。

### 2.2 分配规则是自由参数（不是表示的一部分）

`u_A` / `u_Q` 是 A / Q 上的单位分布，即「形状」。**表示的选择（加法）没有决定形状**，
形状是一个独立的自由参数。三个自然选项：

| 形状 | 公式 | 在 `p(A) = 0` 时 | 在不变式域内与甲案 |
|------|------|----------------|-----------------|
| **(a) 当前形状** | `u_A ∝ p\|_A` | `0/0` 未定义 | **恒等**（见 §2.4 证明） |
| **(b) 均匀** | `u_A = 1/\|A\|` | 有定义 | **不同**（把组内比例压平） |
| **(c) 声明形状** | `u_A ∝ w\|_A` | `w(A) = 0` 时未定义，否则有定义 | 不变式域内恒等；域外不同 |

**这一步是本报告最关键的结构性发现**：把形式化从乘性换成加法，**并不自动解决问题**。
必须同时选形状规则。而 (a) 与甲案同病。

### 2.3 实测（四场景）

| 场景 | 甲 乘性 | 乙(a) 当前形状 | 乙(b) 均匀 | 乙(c) 声明形状 |
|------|--------|--------------|-----------|--------------|
| 1 不变式成立 | `0.185818 / 0.092909 / 0.232273` | **同上** | `0.170667 / 0.168667 / 0.171667` | **同上** |
| 2 不变式破坏 | 保当前比例 `2:1` | 同甲 | 压平 | 转为声明比例 `9:1` |
| 3 目标组为 0（来源二） | **不转移（错）** | **不转移（错）** | `sr = 0.5`（对） | `sr = 0.5`（对） |
| 4 目标组无声明权重（来源一） | 不转移（对） | 不转移（对） | **`ssr = 0.5`（错）** | **不转移（对）** |

（场景 1 三个数字为 `f1 / f2 / s1`；完整输出见文末复现脚本。）

**读法**：

- **乙(a) 当前形状与甲案完全同病**（场景 3 都不转移）。原因见 §2.4 的代数证明。
  所以「换成加法」若同时保留「按当前形状分配」，等于什么都没改。
- **乙(b) 均匀**修好了来源二，但**弄错了来源一**：它把一张池子声明为不可获得的卡抬了起来，
  而那是 2026-10-06 用户明确确认「不转移才对」的情形。
- **乙(c) 声明形状**两个退化场景都对：来源二按声明权重抬起来，来源一因声明权重为 0 而不转移。

### 2.4 代数事实：按当前形状的加法 ≡ 乘性

```
δ_c = t · p_c / p(A)   ⟹   p'_c = p_c + t·p_c/p(A) = p_c · (p(A)+t)/p(A) = p_c · m_c
```

即 `δ ∝ p|_A` 与甲案的常数因子**逐点相同**。反过来也成立：任何常数因子 `m` 都对应
`δ = p(m−1)`。**所以「加法 vs 乘法」在按当前形状时是同一算子，只是参数化不同**；
差别只在参数化在 `p(A) = 0` 处的表现：乘性是 ∞，按当前形状的加法是 `0/0`。**两者都未定义。**

### 2.5 乙案的结论

乙案（纯加法）**不构成一个完整方案**，因为它把决定性的自由度（形状规则）留空，
而三个自然选项里有两个是错的。**它只在选定 (c) 声明形状后才成为方案**，那就是丁案。

## 3. 丙案：混合通道（乘性 + 绝对写入）

### 3.1 推演

接口返回**两种表示之一**：

```
factor 通道： m ∈ Rⁿ_{≥0}      → Φ_m(p) = (m ⊙ p)/⟨m, p⟩
write  通道： q ∈ Δⁿ⁻¹         → Ψ_q(p) = q           （绝对写入，与输入无关）
```

转移族：`p(A) > 0` 走 factor 通道（现状写法），`p(A) = 0` 走 write 通道。

**这条通道不是新发明**：P64 §3.1.5.6 已经为 `assign` 描述过它
（「按口径 3 的分组结果直接写入绝对值，不走因子向量」）。所以框架**本来就需要**它。

### 3.2 性质与代价

| 判据 | 丙案 |
|------|------|
| J1 全域性 | **是**（write 通道无定义域限制） |
| J2 支持增长 | **是**（write 通道可写任意支撑） |
| J4 参数约束 | 混合：factor 侧类型级、write 侧无约束（任意 `q` 都合法） |
| J5 复合律 | **两套**。且 write 是投影（遗忘输入），与 factor 复合时**天然顺序敏感**，正是 §3.1.5.3 已登记的「约束冲突（语义）」类 |
| J6 求解器 | 不需要 |

**代价集中在「两套」**：§3.1.5.3 复合律、§3.1.5.5 可交换性判据、§3.12 组合正确性、
§3.13 不变式校验，每一处都要**对两套各做一遍**，还要额外定义跨表示的复合规则。

### 3.3 结论：被丁案支配

丙案**没有回答形状问题**，只是把它从 factor 通道挪到了 write 通道：写 `q` 时
「A 内部怎么分」仍要定，而丙案没定。

更要紧的是：**丁案用单一表示（加法）就覆盖了同一个能力**（§4.3 场景 3 实测）。
既然加法表示**已经包含**乘性（`δ = p ⊙ (m−1)` 恒有定义），丙案的「保留乘性为默认」
并不提供额外能力，却引入两套形式。**丙案严格劣于丁案。**

## 4. 丁案：加法增量 + 按声明形状分配

### 4.1 推演

由 §0.2 推论 2：转移是 m-测地线上的平移，`δ = t(u_A − u_Q)`。剩下只定形状。
**形状规则的唯一正确约束来自两边的物理含义**：

- **取（Q）必须按当前形状。** 因为只能取**已有的**质量：`δ_c = −t·p_c/p(Q)` 保证
  `p'_c = p_c(1 − t/p(Q)) ≥ 0` 当且仅当 `t ≤ p(Q)`。这是 §3.9.4 已经写下的前置条件。
  若改用声明形状，`t·w_c/w(Q)` 可能超过 `p_c`，产出负概率。
- **给（A）应当按声明形状。** 因为「A 该长什么样」是**池子的声明**，而当前形状可能
  是别的保底干扰后的残形；且声明形状在 `p(A) = 0` 时**依然有定义**（只要该组有声明权重）。

于是：

```
δ_c = + t · w_c / w(A)      c ∈ A
δ_c = − t · p_c / p(Q)      c ∈ Q
δ_c = 0                     其余
Ψ_δ(p) = (p + δ) / Σ(p + δ)          Σδ = t − t = 0，归一化退化为恒等
```

**非对称不是权宜，是两边的物理含义不同**：给是「按声明摆形状」，取是「只能取已有的」。

### 4.2 全域性

| 情形 | 行为 | 对不对 |
|------|------|-------|
| `w(A) > 0` 且 `p(Q) > 0` | 正常转移 | 对 |
| `w(A) = 0`（池子声明 A 不可获得） | 不转移 | **对**（来源一） |
| `p(A) = 0` 但 `w(A) > 0`（被别的保底清零） | **转移，A 从 0 抬到 t** | **对**（来源二） |
| `p(Q) = 0` | 不转移 | 对（无可取） |

**唯一的退化点恰好落在「不转移才对」的那一处。** 这是丁案最漂亮的性质：
它不需要一个「例外」，那个点被形状规则自然排除。

### 4.3 实测（与 §2.3 同一组四场景）

| 场景 | 丁案输出 | 判定 |
|------|---------|------|
| 1 不变式成立 | `f1=0.185818  f2=0.092909  s1=0.232273  sr1=0.024722  r1=0.464278` | 与甲案**逐点相同** |
| 2 不变式破坏 | `f1=0.364000  f2=0.042000  s1=0.105000  sr1=0.024722  r1=0.464278` | 与甲案不同（见 §4.4） |
| 3 目标组为 0（来源二） | `ssr=1.0  sr=0.5  r=0.5` | **对**（甲案不转移） |
| 4 目标组无声明权重（来源一） | 不转移 | **对**（乙(b) 均匀在此错） |

四场景 `Σ` 均与输入一致（丁案不造质量，也不消质量）。

### 4.4 与甲案的关系：两种「保守」程度

| | 给（A）的规则 | 与甲案一致的范围 |
|---|---|---|
| **丁** | 恒按声明形状 `w` | **不变式域内**逐点相同（`p\|_A ∝ w\|_A` 时二者代数等价，见下）；域外不同 |
| **丁′** | `p(A) > 0` 时按当前形状、`p(A) = 0` 时按声明形状 | **甲案的全部定义域内**逐点相同；只在 `p(A) = 0` 处新增定义 |

**丁 在不变式域内与甲案等价的证明**：设 `p_c = p(A)·w_c/w(A)`，则

```
p'_c = p_c + t·w_c/w(A) = (p(A) + t)·w_c/w(A)  ⟹  p'|_A ∝ w|_A，组内总量 p(A)+t
```

与甲案的 `p_c·(p(A)+t)/p(A) = (p(A)+t)·w_c/w(A)` **逐项相同**。

**丁 与甲案在域外的分歧**（场景 2 实测）：甲案保持当前比例（`2:1`），丁案转为声明比例（`9:1`）。
两者给出的**组内总量相同**（`0.511`），只是组内形状不同。这不是错误，是**在定理 1 划定的适用范围之外**做了一次新定义。

**一处必须澄清的混淆**：§3.1.5.2.4 修正 ① 曾判「用基础权重」为错（「组内比例平方放大：基础 3:1 变 9:1」）。
那是**乘性**地乘 `w_c`（`p'_c ∝ w_c·p_c`，不变式下得 `w_c²`）。丁案是**加性地**加 `t·w_c/w(A)`，
是**一次**比例，不是平方。**两者不是同一个操作**，修正 ① 的结论不适用于丁案。

### 4.5 待裁决的一处

丁 与 丁′ 的差别只在「不变式域外怎么办」，而这正是 §3.1.5.4 修正 ① 已经承认「旧实现做错了」的那片地。
故：

- 若希望**最小改动**（只填洞，不动既有语义）：取 **丁′**（分段，域外仍按当前形状）。
- 若希望**单一公式 + 语义更稳**（组内形状以池子声明为准，不受其它保底干扰）：取 **丁**。
  代价是 §3.1.5.2.3 的「A 内常数因子（保持当前比例）」须改写为「A 内按声明形状分配增量」。

**推荐丁**，理由是 J1 的干净度（无分段、无例外）与「形状以声明为准」的语义稳健性；
但这是一处**需要明确裁决的语义升级**，不是免费的一致性修复。

## 5. 判据视角：约束化（不作为候选，作为判据）

### 5.1 推演

把每个保底写成对输出的**约束**（如 `Σ_{c∈A} p_c ≥ f(p)`），框架求「最接近输入且满足全部约束」的分布：

```
q* = argmin_{q ∈ Δ, q 满足全部约束} KL(q ‖ p)
```

### 5.2 闭式解就是乘性因子

线性约束下的 KL 投影是**指数倾斜**：

```
q*_c ∝ p_c · exp( Σⱼ λⱼ gⱼ(c) )
```

即 `q* = Φ_m(p)`，其中 `m = exp(Σλⱼ gⱼ)`。**乘性因子不是「一种参数化」，它是这个变分问题的闭式解**，
拉格朗日乘子就是它的自然参数。这就解释了为什么 §3.1.5.1 要引「指数族」。

### 5.3 它也解释了支持墙

指数倾斜**造不出支撑**（`p_c = 0 ⟹ q*_c = 0`），且约束「把 A 从 0 抬到 t」在指数族内**不可行**。
所以约束化**不能**修好来源二；它把甲案的墙**原样继承**，只是换了个说法。

### 5.4 它的价值：给出正确的判据与三个副产品

| 副产品 | 说明 |
|--------|------|
| **顺序无关** | 约束是集合而非序列，冲突时较严约束自然胜出。§3.1.5.3 的顺序敏感在语义上被消除 |
| **判据统一** | 「是否可表达」变成「是否可行」，比逐元素比因子乘积干净 |
| **代价明确** | 求解远比顺序应用贵，且 `assign` 是绝对赋值（非齐次约束），写成约束要引入常数项 |

**结论：约束化不作为候选**（它不解决本问题），但它是判断候选好坏的**正确框架**：
丁案可以理解为「把转移写成约束 `p(A) 增加到 p(A)+t` 的一个**可全域求解**的显式解」，
而甲案是同一约束在指数族内的解（故只在可行域内有定义）。

## 6. 对比表

| 判据 | 甲 乘性（现状） | 乙 加法（形状留空） | 丙 混合通道 | **丁 加法 + 声明形状** |
|------|:---:|:---:|:---:|:---:|
| J1 全域性 | ✗ | 取决于形状 | ✓ | **✓（唯一退化点=应不转移处）** |
| J2 支持增长 | ✗（结构上不行） | ✓（若选 b/c） | ✓ | **✓** |
| J3 不变式域内与现状一致 | 自身 | (a) 恒等 / (b) 否 | ✓ | **✓（丁/丁′ 皆）** |
| J4 参数约束 | **类型级**（优势） | 值依赖 `δ ≥ −p` | 混合 | 值依赖，但转移族退化为标量 `t ≤ p(Q)` |
| J5 复合律 | `⊙` 一个 | `+` 一个 | **两套 + 跨表示规则** | **`+` 一个** |
| J6 求解器 | 不需要 | 不需要 | 不需要 | 不需要 |
| 来源一（声明不可获得） | 对 | (b) **错** | 取决于写什么 | **对** |
| 来源二（被清零） | **错** | (a) 错 / (b)(c) 对 | 对 | **对** |
| 表示数量 | 1 | 1 | **2** | **1** |

**读法**：丙案在 J5 与「表示数量」上明显差，且不提供乙/丁没有的能力（加法已包含乘性），
故被支配。乙案在 J1 上不闭合（把形状留空）。**丁案在除 J4 外的所有判据上不劣于甲案，
且在甲案失败的两处（J1 / J2）正确**。J4 是甲案唯一的优势，而丁案把它降为单个标量条件。

## 7. 推荐与代价

**推荐：丁案（加法增量 + 按声明形状分配），接口改为 `delta(view, dist, ctx) -> Optional[Dict[str, float]]`。**

理由按判据：J1 干净（无分段、无例外，唯一退化点恰是应不转移处）、J2 支持可增长、
J3 在定理 1 的适用域内与现行规则逐点一致（实测场景 1 三个数值完全相同）、
J5 单一复合律、J4 的代价降为 `t ≤ p(Q)` 一个标量且 §3.9.4 已写。

**必须如实记账的代价**：

1. **这是 Modifier 层的重新规划，不是编辑。** 改写面：§3.1.5.1–.6 全节、§3.9.2 接口、
   §3.9.4 助手、§3.9.5、§3.10、§3.12/§3.13 不变式与验收、§3.14 条件转发、§3.1.4 骨架、
   §3.1.2 的 D20、§六 断言、§七 的 S3/S4/S8/S9 任务块。
2. **J4 从类型级降为值依赖。** 甲案「`m ≥ 0` 与 `p` 无关」这一条会失去，代之以
   「`t ≤ p(Q)`」与「`Σδ = 0`」两条值依赖条件。对转移族这是单个标量，但**对未来的
   非转移机制，加法接口要求作者自己保证非负**（甲案不需要）。这是真实的退让。
3. **换加法买不到的**：顺序敏感**不会**消失。`δ` 仍通过 `p(Q)` 依赖当前分布，
   「在 `δ₁` 的输出上求值 `δ₂`」与原处求值仍不同。§3.1.5.3 的分析长度不变。
4. **前置欠账**：§3.1.5.3/.4/.5 与 §3.9.3/.5 至今仍写在 §3.1.5.2 已宣告作废的
   `share` / `assign` / `(U, T, 运算)` 词汇里（全文 `share` 29 处、`assign` 20 处）。
   改形式化之前或同时须先迁词汇，否则新旧口径并存。

**若上述代价不可接受**，次优是**丁′**（分段版本）：改动面与丁相同，但域外语义不动，
等价于「只给甲案补一个 `p(A) = 0` 的定义」。它放弃了单一公式，换来零语义变更。

## 8. 裁决结果（2026-10-08，用户裁决）

> **本文的甲 / 乙 / 丙 / 丁之争已作废。** 争点不在「选哪个表示」，而在「A 侧形状由谁定」，
> 结论是**逐机制指定**。依据是本文写作之后的两组实测：
> `.recycle_bin/probe_shape_rules.py` 与 `.recycle_bin/probe_pA0_reach.py`。

### 8.1 争点为何消失

三案的共同前提是「需要一个统一的表示与统一的形状规则，使复合自洽」。该前提在新口径下作废：

- **口径变更**：目标改为「每个 modifier 及其复合的行为语义合理，能正确表达所有保底」，
  不再要求与旧实现逐场一致（J3 放宽）
- **表示之争（乘性 / 加法）随之消失**：接口本来就是「返回任意因子向量」（P64 §3.1.2），
  表示是实现细节，不进选型
- **统一形状之争随之消失**：A 侧形状属于机制自身的语义，逐机制声明即可

### 8.2 仍受约束的部分

**Q 侧形状必须按当前形状 `p_c / p(Q)`，不可自由。** 反证：设 Q 侧分配比例 `v` 与 `p` 无关
且 `v_c > 0`，令 `p_c → 0`（其余不变），则 `t·v_c ≤ p_c` 必在某处失效，产出负概率。
故 Q 侧的值依赖是「只能取已有的」这一物理事实的推论，丁案把 J4 的代价压成单个标量
`t ≤ p(Q)` 正源于此。**能自由指定的只有 A 侧。**

### 8.3 实测一：A 侧形状决定复合行为（`rotating + soft`）

场景：SSR 组 = `ssr_featured`（UP）/ `ssr`（常驻），声明与初始分布同为 1:1；
guaranteed 与 boost = 6% 同时触发。第一行为**跑真代码**（`RotatingBehavior` + `SoftStepBehavior`），
第二行为按 §4.1 公式推演（新框架未实现，只能推演）。

| 方案 | `[rotating, soft]` | `[soft, rotating]` | 可交换 |
|---|---|---|---|
| 甲 / 丁′（A 侧按当前形状，真代码） | UP=0.066000 STD=0.000000 | UP=0.066000 STD=0.000000 | 是 |
| 丁（A 侧按声明形状，推演） | UP=0.036000 **STD=0.030000** | UP=0.066000 STD=0.000000 | **否** |

**读法**：丁案的 A 侧按声明形状，会在 `[rotating, soft]` 下把 rotating 已排除的常驻 SSR 抬回
0.030。而 `soft` 的语义只是「提高 SSR 总量」，对组内形状没有意见。故 **`soft` 这类机制应取当前形状**。

### 8.4 实测二：A 侧形状也决定域外行为（穷举）

穷举 7 个机制形态 × 3 个 scope × 状态变体，在 `_validate_behaviors` 四条规则的合法配置内，
找「X 之后 `p(A_Y) = 0` 且 `p(Q_Y) > 0`」的组合。依据两条定稿规格：夺取型算子的 `Q_X` 内
各卡因子为 0，故 `p(A_Y) = 0 ⟺ A_Y ⊆ Q_X`、`p(Q_Y) > 0 ⟺ Q_Y ⊄ Q_X`。

| X（清空方） | Y（要抬起方） |
|---|---|
| `H_tfT(ssr)` | `NF(ssr)`、`Sel(ssr)` |
| `NF(ssr)` | `H_tfT(ssr)` |
| `Sel(ssr)` | `H_tfT(ssr)` |

**读法**：这类退化**可达，但只在语义直接对撞的配置下**（全部是「一个算子夺走 UP，另一个要保 UP」）。
按 §1.5 的顺序语义，后执行的算子应当生效；甲案在 `p(A) = 0` 处不转移会让它静默失效。
故这些机制（`H_tfT` / `NF` / `Sel`）应取**声明形状**。

**同时更正**：§3.1.5.6.1 只测了 `hard → hard → soft` 一条链，未覆盖 `NF/Sel → H_tfT` 这条；
「来源二在新框架下不可达」这一推论**不成立**。

### 8.5 裁决

1. `transfer_factors(dist, A, Q, amount)` 增加 `shape` 形参，取值 `'current'` / `'declared'`
2. `shape` 是 `factor()` 方法体内的**第五个局部量**（与条件 / A / Q / 转移量并列），
   不进构造形参、不改 `delta(view, dist, ctx)` 签名
3. 分发：**可能遇到 `p(A) = 0` 的机制取 `'declared'`**（`H_tfT` / `NF` / `Sel`），
   **其余取 `'current'`**（`H_tfF` / `S` / `R` / `NO`）；依据即 §8.3 与 §8.4。
   **2026-10-08 已落地**：`declared` 分支已实现（`weights` 形参接 `ctx.base_probabilities`），
   三个机制在 §3.1.2 的「A 侧形状」列标为 `declared`，见 P64 §3.1.2 / §3.9.4
4. 甲 / 乙 / 丙 / 丁 不再作为选型候选，本文其余各节的对比表保留作推演过程记录

### 8.6 对 P64 的改写要求（尚未执行）

- §3.1.5：形式化定位由「统一表示选型」改为「A 侧形状逐机制声明 + Q 侧值依赖不可避免」
- §3.1.5.6.1：按 §8.4 更正可达性结论
- §3.9.4：`transfer_factors` 签名加 `shape`
- §3.1.2：机制表加一列「A 侧形状」，标注 7 个形态各自的取值
- §7 的代价清单：按新形态重述（J4 的值依赖仍在、顺序敏感仍在，
  但本文实测新增的那条「丁案引入顺序敏感」随丁案一起撤回）
