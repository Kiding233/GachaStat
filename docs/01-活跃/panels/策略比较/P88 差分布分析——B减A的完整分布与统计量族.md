## 一、问题

### 1.1 现有对比分析缺一层

对比分析面板（`gui/comparison_analysis_panel.py`）现在是四层：

| 层 | 内容 | 产出形态 |
|---|---|---|
| L1 | `DescriptiveStats` 描述统计 + PMF/ECDF 叠加 | 每数据集一行标量 + 分布图 |
| L2 | DD Bootstrap 随机占优（FSD/SSD/TSD，PySDTest Donald-Hsu 2016） | n×n 二元显著标记矩阵 |
| L3 | 假设检验（KS/MWU/ttest + Holm/BH 校正） | n×n p 值矩阵 |
| L4 | 双 GDR 帕累托前沿 | 散点 + 前沿连线 |

缺的是**成对差异的完整分布**。现有各层都只给点或二元判定：

- L1 只给单数据集的边际汇总，两个数据集的差只体现在「均值差」这一个数上
- L2 给「是否随机占优」的二元结论 + p 值，不给「差多少、多大概率」
- L3 给 p 值，但 p 值回答的是「能否拒绝无差异」，不是「差异有多大、朝哪边」

具体缺什么，用三个现有面板答不出的问句说明：

- 「B 比 A 多拿至少 1 张目标卡的概率是多少？」
- 「两个策略的结果在多大比例的模拟里完全一样？」
- 「B 相对 A 的平均增益是多少、平均损失是多少、比值多少？」

这三个问句背后的量，L2 的 FSD 检验在数学上隐含（Strassen 定理：A 一阶随机占优 B 等价于存在某耦合使 **A ≥ B** 几乎必然），但从未被显式报出。L3 的 Mann-Whitney 统计量经归一化后是**中秩口径** `P(B>A) + ½P(B=A)`（scipy 按平均秩计算，2026-10-08 实测验证），**不是**严格的 `P(B>A)`；且 L3 现存的是**原始 U、未归一化**（`core/comparison_analyzer.py:704` 直接存 `float(stat)`），该量同样从未被显式报出。

### 1.3 范围界定：只做卷积版

D = B − A 的分布有两种语义：

| 版本 | 构造 | 语义 | 本计划 |
|---|---|---|---|
| 配对版 | 同随机数下 `d_i = b_i − a_i` | 同一运气下换策略（弱化反事实） | **不做** |
| 卷积版 | 两批独立样本的差 `F_B * F_{−A}` | 重开一局换策略（含运气差异） | **做** |

不做配对版的**实测依据**（非判断，是查证结果）：

1. `service/batch_simulator.py` 并行路径用 `imap_unordered`，`aggregate_data` 按完成顺序排列，与 seed 顺序无关
2. `core/streaming.py` 的 `extract_aggregate` 产出的记录**无 seed 字段**，事后无法回溯排序
3. `core/pool.py` 用 `random.random()` 顺序消费随机数，两条轨迹仅在动作序列完全一致的前期共用随机数流，一旦分叉即错位

即「同种子索引配对」当前物理上做不到，需先补 seed 溯源基础设施。配对版留作后续增量（见 §三.6）。

卷积版的额外优势：均值层面零信息损失（`E[D] = E[B] − E[A]` 是期望线性性的恒等式，配对与否均成立），且与现有数据管线零冲突（并行路径产出的样本天然独立）。

## 二、目标

1. **给定两个数据集与一个 GDR，产出 D = B − A 的完整经验分布**，精确（不是近似），且成本与样本量解耦
2. **产出一族差分布统计量**：中心、三段概率、正负期望分解、离散度，各带置信区间
3. **呈现层落在对比分析面板**，默认视图为 D 的 PMF，累积视图为 CDF
4. **与现有 L3 交叉自洽**：满足中秩恒等式 `P(D>0) + ½·P(D=0) == scipy U/(n_A·n_B)`（容差 1e-12）。**注意 scipy 的 U 是中秩口径，不等于严格 `P(D>0)`**；格点 GDR 上 `P(D=0)` 可达 20% 以上，两者实测可差 20% 以上，写成「与 U 一致」必然验收失败

## 三、方案

### 3.1 核心算法：唯一值压缩 + 唯一值对枚举（设计定稿）

**不用 `np.convolve`，不用等距直方图。** 实测依据见 §3.2。

```
uA, cA = np.unique(a, return_counts=True)      # 唯一值 + 频数
uB, cB = np.unique(b, return_counts=True)
d = (uB[None, :] - uA[:, None]).ravel()        # |uA|·|uB| 个差值
w = (cB[None, :] * cA[:, None]).ravel()        # 对应权重
# 按差值聚合：np.unique(d, return_inverse=True) + np.add.at(c, inv, w)
# 概率 = c / c.sum()
```

成本 O(|u_A|·|u_B|)。实测 |u| 在 25 上下，即约 600 次运算；输出支撑最多 600 余点，符合项目 O(1) 内存口径。

**「与 n 无关」有边界，必须区分两类 GDR**：整数格点与有理格点型的 |u| 上限由「值域 ÷ 格距」决定，**不随 n 增长**（§3.3 实测）；但**不等距连续型**（`resource_efficiency`、`weapon_character_ratio`）的 |u| ≈ 0.117·n，**随 n 线性增长**。n = 1e5 时 |u| ≈ 1.2e4，|u_A|·|u_B| ≈ 1.4e8，点估计尚可但 bootstrap 不可行（见 §3.5：bootstrap 不走本路径）。保护分支阈值 1e6 只护住点估计，不护 bootstrap。

保护分支：若 |u_A|·|u_B| 超过阈值（建议 1e6），退回 ECDF 采样或 FFT。按实测此分支不会触发。

### 3.2 精确性实证（不依赖判断，已跑数）

把 6 个 GDR 的样本对半分成 A、B 两组（独立样本，符合卷积语义），压缩路径与暴力枚举 O(n_A·n_B) 逐点对照：

| GDR | nA/nB | \|uA\|/\|uB\| | 暴力对数 | 压缩对数 | D 支撑 | 最大差值偏差 | 概率最大偏差 | 概率和 |
|---|---|---|---|---|---|---|---|---|
| resource_remaining | 200/200 | 24/23 | 40000 | 552 | 204 | 0 | 0 | 1.000000000000 |
| non_pity_draws | 200/200 | 24/24 | 40000 | 576 | 204 | 0 | 0 | 1.000000000000 |
| resource_efficiency | 200/200 | 27/25 | 40000 | 675 | 669 | 0 | 0 | 1.000000000000 |
| target_achievement | 200/200 | 3/3 | 40000 | 9 | 7 | 0 | 0 | 1.000000000000 |
| resource_per_card | 200/200 | 27/25 | 40000 | 675 | 470 | 0 | 0 | 1.000000000000 |
| weighted_satisfaction | 200/200 | 3/3 | 40000 | 9 | 5 | 0 | 0 | 1.000000000000 |

`dmax = 0`、`pmax_diff = 0`，是逐位相同而非接近。

**为何不用 `np.convolve`（实测反例）：**

| GDR | 暴力支撑 | np.convolve 输出长度 | 一致 |
|---|---|---|---|
| resource_remaining | 204 | 40481 | 否 |
| non_pity_draws | 204 | 258 | 否 |
| pity_draws | 5 | 5 | 是 |
| all_targets | 3 | 3 | 是 |

原因：`np.convolve` 要求格距为 1 的稠密数组。资源类 GDR 格距 160（单抽成本），值域 13760，输出 40481 个桶而真实支撑仅 204 个，多出的是零概率填充。格距越大浪费越狠。

### 3.3 GDR 取值形态实测（n=300，决定实现分支）

| 类型 | GDR | 实测特征 |
|---|---|---|
| 整数格点 | resource_remaining, resource_consumed, non_pity_draws, pity_draws, target_card_draws, weighted_satisfaction, total_card_value, all_targets, extra_target | 格距 160（资源类）或 1（计数类） |
| 有理格点（分母固定） | target_achievement, target_collection, per_pool_draw_rate（格距 1/6）、resource_per_card（格距 80/3） | 乘固定分母即整数 |
| 不等距连续 | **resource_efficiency**（值域 1e-4，最小间距 2e-7，35 个不同值）、weapon_character_ratio | **无公共格距**，乘任何因子都无法整除 |

第三类证明「先放大成整数再卷积」走不通：`resource_efficiency = achieved/consumed`，consumed 每次不同（49920 到 63680，160 的倍数），分母变动导致无公共格距。而压缩路径对三类**统一处理**，这是它优于等距直方图的根本原因。

实测 distinct/n 比值：最高 0.117（resource_efficiency），最低 0.003。**对整数与有理格点型**，n 增大时 |u| 的上限由「值域 ÷ 格距」决定，不由 n 决定；**不等距连续型不适用此结论**（见 §3.1 的边界说明）。

### 3.4 统计量族（设计定稿）

| 类别 | 统计量 | 说明 |
|---|---|---|
| 中心 | `E[D]`、中位数、各分位数 | `E[D] = E[B] − E[A]` 恒等式；**差值的分位数 ≠ 分位数之差**，实现须写死用前者 |
| 三段概率 | `P(D<0)`、`P(D=0)`、`P(D>0)`（=CLES）、`P(D>δ)`、`P(D<−δ)`、`P(\|D\|≤δ)` | 前三个构成**完备三分类**（和为 1；离散下 `P(D≥0)`/`P(D≤0)` 与 `P(D>0)`/`P(D<0)` 均不同，须区分）。`P(D=0)` 是抽卡场景主力项，不可省；`P(D<0)` 与 `P(D>0)` 对称，报优势概率须同时报劣势概率，否则用户会误读为「B 要么更好要么打平」 |
| 正负分解 | `E[D⁺] = E[max(D,0)]`、`E[D⁻] = E[max(−D,0)]`、比值 | 恒等式 `E[D] = E[D⁺] − E[D⁻]`；`E[D⁻]` 是下侧部分矩 LPM(1)；比值即盈亏比 |
| 离散 | Var、标准差、IQR | IQR 对厚尾比 std 稳健 |

**δ 的性质**：用户显式输入的可选参数，不在默认路径上，整组统计量挂在 `P(D>x)` 曲线后面按需取。因此不构成 P19 第 5 项（Almost Stochastic Dominance）被暂缓的同一问题（那项要做默认路径且无自然取值）。建议默认值从 GDR 语义导出（如「多 1 张目标卡」），UI 可调并显示对应的绝对量。

**统一形式（可选）**：`Ω(θ) = E[(D−θ)⁺] / E[(θ−D)⁺]`（Omega 比率，θ 即 δ，Keating & Shadwick 2002）。分子是「超出 θ 的平均幅度」，分母是「低于 θ 的平均幅度」，比值即阈值 θ 处的上行/下行幅度比。

三个性质（决定它可作为完整刻画）：

1. **与分布一一对应**。分部积分给出 `E[(D−θ)⁺] = ∫_θ^∞ (1−F(x))dx`、`E[(θ−D)⁺] = ∫_{-∞}^θ F(x)dx`，故 `Ω(θ) = [∫_θ^∞ S(x)dx] / [∫_{-∞}^θ F(x)dx]`（S = 1−F）。两个累积积分由 F 唯一决定，反之 F 也可由 Ω 唯一还原。
2. **单调递减**。θ 增大时分子减、分母增，故 Ω 在 D 的支撑上严格递减，从 +∞ 降到 0。
3. **θ = 0 处的判据**。`Ω(0) ≥ 1 ⟺ E[D⁺] ≥ E[D⁻] ⟺ E[D] ≥ 0`（因 `E[D] = E[D⁺] − E[D⁻]`）。即 Ω 曲线与 1 的交点给出「均值盈亏平衡阈值」θ*。

**画图**：横轴 θ、纵轴 Ω(θ)，一条从左上到右下的单调曲线，叠加 Ω = 1 水平线。2026-10-08 实测示例见 `output/p88_omega_demo.png`（四个 GDR，含离散折线与连续折线两种形态）。

**两处必须写准，否则会误导**（2026-10-08 独立审查指出并经复核）：

1. **只有比值型统计量是曲线上的读数点**。`E[D⁺]/E[D⁻] = Ω(0)` 确实在曲线上；但 `P(D>0) = −G′(0)`（分子 G 的导数）、分位数由 `F(ξ_q)=q` 定义，**都不是曲线上的读数**，需要求导或还原才能得到。故「三段概率、分位数都是这条曲线上的取样点」是错的，应表述为「Ω 完整决定分布，故这些量可由曲线还原，但并非曲线上的直接读数」。
2. **θ\* ≡ E[D]，不构成新统计量**。恒等式 `G(θ) − L(θ) = E[D] − θ` 给出 `Ω(θ)=1 ⟺ θ = E[D]`，即交点就是均值的另一种求法（实测 θ\* 与 E[D] 逐位相等）。作为一致性校验可用，但**不得作为独立呈现项**，否则会让用户以为是新信息。

**还原路径（补全一一对应的推导）**：由 `G − L = E[D] − θ` 与 `Ω = G/L` 得 `G(θ) = Ω(θ)·(θ − E[D]) / (1 − Ω(θ))`，再由 `S(θ) = −G′(θ)` 还原生存函数。格点数据上 G 分段线性，还原须利用 Ω 导数在支撑点处的跳变恢复原子质量。三个实现注意：(a) 分子或分母为 0 时 Ω 取 0 或 ∞，θ 定义域须限制在 D 的支撑内并截断显示；(b) 值域跨度大，纵轴宜用对数刻度或改画 `1/Ω`；(c) 格点数据上 **G、L 分段线性**（直线段），**Ω = G/L 分段分式线性**（段内是光滑曲线，不是直线），支撑点处一阶导数跳变，跳变量为 `p_j(L−G)/L²`（2026-10-08 实测：跳变量 −15.0000 与公式吻合到 4 位）；**在 Ω = 1 的支撑点处跳变量为 0，该点无折点**，这是「E[D] = 0 时 Ω(0) = 1 恰落在支撑点上则曲线该处完全光滑」的原因。

### 3.5 精度：闭式为主，bootstrap 为辅（2026-10-08 独立审查后修订）

**必须避开的坑**：`P(D>0) = (1/(n_A·n_B)) ΣΣ 1[b_j > a_i]` 表面是 n_A·n_B 个伯努利样本，但这些指示变量严重不独立（共用同一批 a 和 b）。严格结果是

```
Var(θ̂) = ζ₁/n_A + ζ₂/n_B + o(1/n)，  ζ₁ = Var_A(P(B>a))，ζ₂ = Var_B(P(b>A))
n_eff  = n_A·n_B / (n_A + n_B)  ≤  min(n_A, n_B)
```

平衡时 `n_eff = min/2`。朴素二项 CI 的**方差低估因子约 min(n_A, n_B)**（实测 60/60 为 39 倍、30/300 为 113 倍、200/200 为 131 倍；区间**宽度**低估约 √min 倍）。直接套二项或 Wilson CI 会得出虚假精确的结论。

**主口径改为 Hájek 投影闭式方差**（审查建议，实测覆盖率 0.950 至 0.955，略保守于 bootstrap 但同量级，且 O(n_A+n_B)、无重抽噪声）。这与 ROC 的 AUC 方差是同一估计量，标准引用为 **DeLong, DeLong & Clarke-Pearson (1988), Biometrics 44(3):837-845**（其 Q1/Q2 即 ζ 的对应量）；早期近似式见 Hanley & McNeil (1982), Radiology 143:29-36。

**一处必须写准**：严格 `P(B>A)` 口径下，闭式方差**不需要任何「结修正」**。文献里的 Mann-Whitney 结修正 `n₁n₂/12·[(n+1) − Σ(t³−t)/(n(n−1))]` 是**零假设检验**用的方差，不是 CI 用的；误用它会把 CI 建立在零假设方差上，这是本计划最可能被误实现的一处陷阱。

**bootstrap 的定位**：用于**分位数**（闭式给不出）与**交叉验证**。实现上不必从零造轮子：`scipy.stats.bootstrap` 的 `paired=False`（默认值）就是「各抽各的」两样本重抽，可直接用。

**重抽对象必须是原始数组**（长度 n_A 与 n_B），且每次重抽**直接算统计量**（`P(B>A)` 排序计数 O((n_A+n_B)log(n_A+n_B))），**不走 §3.1 的卷积路径**。理由：(a) 走卷积是 B × O(|u_A|·|u_B|)，在不等距连续型 GDR 上会炸（§3.1 边界）；(b) 重抽「唯一值 + 频数」等价于 Bayesian bootstrap，是另一个估计量。

**理论依据**：`P(D>0)` 的样本估计是 Mann-Whitney 的 A 统计量，即**两样本 U 统计量、核阶 (1,1)**，核 `h(a,b) = 1[b>a]` 有界。它**不是** Fréchet 可微的光滑泛函（示性核不可微）；正确的一阶理论是 **Hájek 投影给出的渐近线性**（核有界故 E[h²]<∞，投影方差有限），在**核非退化**（ζ₁ + ζ₂ > 0）且 `min(n_A,n_B) → ∞`、`n_A/(n_A+n_B) → λ ∈ (0,1)` 下给出渐近正态。bootstrap 一致性的正确文献路线是 U 统计量的 bootstrap 理论（Bickel & Freedman 1981, Ann. Statist. 9(6):1196-1217 §5；Arcones & Giné 1992, Ann. Statist. 20(2):655-674），不是「光滑泛函」那一路。

**方法清单与对照**（阶段 1 实现时逐条落实）：

| 量 | 主口径 | 交叉验证 / 备选 |
|---|---|---|
| `P(D>δ)` 等比例量 | Hájek 投影闭式（严格口径无需结修正） | 两样本 bootstrap；Brunner-Munzel (2000) t 近似（非平衡小样本更优）；logit 或反正弦变换后 Wald |
| `E[D]`、`E[D⁺]`、`E[D⁻]` | 两样本 bootstrap（`paired=False`） | 解析 SE |
| 分位数 | 见下「分位数的原子问题」 | 无闭式可用 |
| `E[D⁺]/E[D⁻]`、`Ω(θ)` | **Fieller 定理区间**，或对数比值 + delta 法，或**只报两个分量各自的 CI**（最稳妥） | 不用朴素 bootstrap（实测宽度 2.80 对真值 1.67，覆盖率 0.930） |
| 核退化检测 | `ζ̂₁/n_A + ζ̂₂/n_B == 0`，或「全部重抽副本给出同一值」 | 见 §3.6.2 |

**分位数的原子问题（审查实测）**：D 的分位数是**卷积的分位数**，没有 F_D 的 i.i.d. 样本，故分布无关的顺序统计量区间不可用；而 bootstrap 分位数区间在**原子处失效**（实测：分位水平落在 `P(D=0)=0.196` 的原子上时覆盖率 1.000、区间宽度塌缩为 0；真值一旦不在原子上覆盖率会掉到 0）。处置：分位水平落在原子上（`P(D = ξ_q)` 超阈值如 5%）时**拒绝报 CI 并提示**；或改报 `(P(D ≤ x), P(D < x))` 这一对比例量（理论健全），由用户读分位点。

**文献核验状态**：本节文献在 2026-10-08 审查时**未能联网核验**（该环境 WebSearch/WebFetch 不可用），卷期页码标为**待确认**，需联网补核。**另须注意**：Newcombe (2006) 的目标参数是**中秩口径** `P(X<Y) + ½P(X=Y)`，与严格 `P(D>0)` 相差 `½P(D=0)`，**对照前必须对齐目标参数**，否则会误判 bootstrap 有偏。

### 3.6 三个实现细节（必须写死）

1. **浮点容差聚类只作用于展示，统计量一律用精确比较**。`resource_efficiency` 实测 675 个唯一值对产生 669 个不同差值（6 对碰撞）。数学上相等的差值在浮点下可能不等（不同运算路径差 1ulp），会把本该合并的桶拆开。四条纪律：
   - 三段概率 `P(D<0)/P(D=0)/P(D>0)` 与 U 统计量一律在**原始配对**上用精确比较（`>`、`<`、`==`）算出；容差聚类**只用于 PMF 的支撑呈现**。否则 `P(D>0)` 不再等于 U 统计量，§六 的交叉校验会被误报为 bug。
   - bootstrap 的每个副本用**同一个**函数，聚类只在最后做一次。若每次重抽都重跑聚类，聚类边界随副本变化，等于给统计量注入副本相关的不连续扰动。
   - 聚类规则须**防链式合并**（相邻扫描会传递，实际合并跨度可超名义容差），且**不得把非零差值并入 0**（0 处原子是本场景语义主角，不是数值噪声）。建议非传递规则：与簇代表元比较，或先归一化到全局尺度再取整。
   - **有界误差须登记**：聚类引入的统计量扰动量级为 O(1e-12 × 尺度)，这是把 §二 目标 1 的「精确」限定为「浮点表示精度内精确，另有一处相对容差 1e-12 的显示层聚类」。

2. **退化判据分三条，不可混用**。
   - `distinct == 1`（或统计量在全部配对上为常数）→ **无变异**，不画图，UI 提示「该指标在当前配置下无变异」。实测当前配置下 `ssr_collection`、`extra_target`、`weapon_character_ratio`、`draw_conversion_efficiency` 属此类。
   - **核（近）退化**：`ζ̂₁/n_A + ζ̂₂/n_B == 0`，或「全部重抽副本给出同一统计量值」→ **bootstrap 无效**，拒绝出区间并提示。这是 bootstrap 唯一真正失效的区域，与上一条是**不同判据**。
   - `distinct < 20` → 既不是无变异也不是核退化，只表示**支撑点少、区间偏宽**，作为精度提示。**注意**：`core/distribution.py` 的 `_count_distinct() < 20` 是为 **EVT 的 GPD 拟合**设的阈值（注释原文「GPD 拟合无意义」），语义不是「退化」，不可直接挪用。

3. **方向约定**。`resource_consumed`（`core/gdr.py:397`）与 `resource_per_card`（`core/gdr.py:431`）是 `lower_is_better = True`，其上 `D = B − A` 为负才是 B 好。沿用现有 `lower_is_better` 标志翻成「越高越好」再算，否则用户在正负号上读反。

### 3.7 呈现层设计（阶段 2，形态待定）

- **默认视图：D 的 PMF 柱状图**。x 轴按实际支撑摆放（去重排序后直接作柱 x 坐标），宽度取相邻支撑间距中位数。理由：D 是单分布无多曲线遮挡问题；实测支撑高度离散（target_achievement 的 D 只有 5~7 个取值），柱状比阶梯好读；`P(D=0)` 原子直接可见；δ 三段着色在柱状上天然（按区间给柱子染色）。
- **累积视图：CDF `F_D(x)`**，不用生存函数。理由：与 L1 的 ECDF、L2 的积分 CDF 方向一致，同一面板内不应出现方向反转。`P(D>x)` 的读数用标注或 hover 补。
- **Y 轴用概率质量，不用密度**。L1 现用 `histnorm='probability density'`（连续模式），那对格点数据是错的，柱子高度会变成 1/格距 的量纲，格距 160 与格距 1 的两个 GDR 之间无法比较。
- **自适应**：支撑小（约 ≤50）用 PMF，支撑大（resource_efficiency 实测 669）用 CDF。参考 `core/gdr_binning.py` 的 `bar_mode` 判据。
- **二项型 GDR 走 RD/NNT 分支**：取值 0/1 的 GDR（如 `all_targets`）差分布只有 −1/0/+1 三个原子，全部统计量退化，`P(D=1)` 即风险差 RD。这类直接报 RD + NNT 更清楚（P19 §效应量专项设计已有此设计）。

## 六、验收标准

**阶段 1**

- [ ] `core/diff_distribution.py` 对任意两个样本数组产出 (支撑, 概率质量)，概率和 = 1（浮点容差 1e-12）
- [ ] 与暴力枚举 O(n_A·n_B) 在 6 个 GDR 上逐点相同（dmax = 0）
- [ ] **中秩恒等式**：`P(D>0) + 0.5*P(D=0) == scipy.stats.mannwhitneyu(...)[0]/(n_A*n_B)`（容差 1e-12）。**不得写成与严格 `P(D>0)` 一致**，两者在格点数据上相差 `½P(D=0)`
- [ ] `E[D]` 与 `mean(b) − mean(a)` 一致（恒等式）
- [ ] 恒等式 `E[D] = E[D⁺] − E[D⁻]` 在随机样本上成立
- [ ] **θ\* 与 E[D] 逐位相等**（Ω 与 1 的交点即均值，作一致性校验，不作独立呈现项）
- [ ] 退化判据三条各自可触发且互不混淆：`distinct == 1`（无变异）、`ζ̂₁/n_A + ζ̂₂/n_B == 0`（核退化，拒绝出区间）、`distinct < 20`（精度提示）
- [ ] `lower_is_better` GDR 上方向翻转正确（用 `resource_consumed` 或 `resource_per_card` 验证）
- [ ] 浮点容差聚类：注入 1ulp 差异的差值对，验证被合并为同一桶；**且验证聚类不改动 `P(D>0)`/`P(D=0)`/`P(D<0)`**（统计量走精确比较路径）
- [ ] 容差聚类**防链式合并**（构造三点链式案例，验证实际合并跨度不超名义容差）；**不得把非零差值并入 0**
- [ ] **覆盖率模拟**：真值用穷举卷积或高精度数值积分获得（写明精度），蒙特卡洛重复数 **R ≥ 1000** 并报告 MC 标准误；场景至少含：连续对称 / 连续厚尾 / 整数格点 / 有结离散 / **n_A ≠ n_B**（如 30/300、15/150）/ 极小 n（15/15）/ **P 接近 0 或 1** / **二项型 0/1 指标**
- [ ] 覆盖率带 [0.90, 0.98] **只适用于比例量与矩量**；下界针对欠覆盖、上界针对过保守。**分位数另立判据**
- [ ] **分位数原子守**：构造 `P(D=0)` 大原子的输入，验证落在原子上的分位水平**拒绝报 CI 并给出提示**
- [ ] **近退化核守**：构造 ζ̂ ≈ 0 的输入（如 D ≡ 0），验证**拒绝出区间**而非返回 nan
- [ ] 闭式与 bootstrap 对照判据**定量**：宽度相对差 ≤ 15%、**中心相对差 ≤ 5%**（中心差能直接抓到 tie 约定错配）；与 Newcombe 对照前须**对齐目标参数**（其参数含 ½ 结项）
