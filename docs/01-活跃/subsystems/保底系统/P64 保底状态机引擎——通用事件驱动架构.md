## 预留方向

- **四维抽象**：触发器（SSR事件 / 抽数事件） × 选择器（is_featured / is_selected_card / custom） × 拓扑（guarantee / streak / inverse / bidirectional） × 效果（force_featured / force_loss / base_ratio）
- **`type="custom"`**：TOML 直接声明 states + transitions + effects 的配置语法
- **debug 工具**：`--debug-pity` 模式——每抽打印状态转移日志
