## 四、缺失边界检查

### 🟠 [中] `match_overflow_bands` 文档承诺排序、实现未排序 + ∞ 区间遮蔽（`overflow.py:24-55`，P63 新增）

docstring 声明「区间互斥，**顺序无关——内部会排序**」，但实现：

```python
for band in bands:                      # 无排序
    if band.min <= n:
        if band.max is None or n <= band.max:
            return dict(band.resources)  # 首个命中即返回
```

**遮蔽场景**：`[OverflowBand(1, None, {C:25}), OverflowBand(3, 3, {A:10})]`，n=3 时先命中 `[1,∞)` → 返回 `{C:25}`，`[3,3]` 永远不可达。

- **当前侥幸正确**：唯一调用链 `config_toml.py → expand_sugar_to_bands()`（已按 min 排序 + 互斥保证）恰好避开
- **测试误导**：`test_match_unordered_input`（MATCH-7）命名「验证匹配不依赖输入顺序」，仅覆盖**非重叠乱序**（`[8,None]` 在 `[1,1]` 前，n=1 时 `8<=1` 不成立自然跳过）——∞ 区间遮蔽未覆盖
- **风险**：GUI 编辑器或 P58 milestone 直接构造 bands 列表时，顺序/重叠错误将静默产出错误溢出资源，无告警
- **建议**：实现首行排序（`bands = sorted(bands, key=lambda b: (b.min, b.max is None))`）以兑现文档承诺，或删除「内部会排序」表述；补 ∞ 区间遮蔽测试

### 🟠 [中] `PriorityChainStrategy` docstring 与实现不一致（`strategy.py:216-239`，P69 阶段 3 新增）

docstring 声称「第一个返回**非 None 且非 WaitAction(duration=0)** 的结果被采纳；若全部返回 WaitAction(0)，则返回最后一个」，实现为：

```python
for strategy in self.strategies:
    action = strategy.select_action(ctx)
    if action is not None:      # WaitAction(0) 也会被立即采纳
        return action
return WaitAction(duration=0)   # 全部 None 时返回新 WaitAction(0)，而非"最后一个"
```

复合策略是插件 building block，文档描述的「跳过无操作等待」语义与实现背离，插件开发者按 docstring 理解会踩坑。**建议**：按真实语义改写 docstring（实现无错，文档有错）。

### 🟡 [低] `plotly_charts.py:695` 过时注释

`fixedrange=False` 已允许垂直拖动，但注释仍写「限制垂直拖动：y 轴固定范围，仅允许横向平移」。本周 `fixedrange` 改动（7dc45a9）引入后未同步注释。

### 🟡 [低] `IntParam` / `PoolIntMapParam` 接受 bool 值

`float(True) == 1.0` → `IntParam.validate(True)` 静默返回 1（`PoolIntMapParam` 同理）。bool 是 int 子类的 Python 惯用陷阱，当前无实际触发路径，属防御性建议（`isinstance(v, bool) and not isinstance(v, int)` 先拒绝）。
