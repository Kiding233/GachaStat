C 段 · 基于 8（card 式）的六个变体

8 的 tag 间间隔显大，原因是 gap:3px 加上每个 tag 各自的左右边框，等于两条边框中间夹一条空缝。 C 段统一先把间距收紧（相邻 tag 共边，用负外边距吃掉重复的那一条），再逐项试「文字左边加点东西」。 标记全部用同一档灰，不占用语义色。

D 段 · 预览各归各家（第二个重做）

前两版都被否：右缘全高道与「分析窗那条道」同缘同形，用户分不清点哪个；改成配置页内的页底带或页内右栏，又被「对多数页面是无关信息还占地方」否掉。
根因：预览的三块内容只与 5 个标签页相关（资源定义、资源获取、卡池管理、保底机制、累抽奖励），另外 6 个（卡牌定义、抽卡策略、停止条件、目标卡、权重配置、满突溢出）看它毫无用处。做成全局的东西，等于让一半的页面养一个跟自己无关的面板。
新方向：拆开，各归各家。每块可视化只出现在它解释的那一页里，形态也随该页的内容而定（时间轴 / 曲线 / 阈值尺），不是一套东西缩小了搬进去。

D-A · 卡池管理（池）

页面内嵌一条本 Banner 的时间轴，画出各池的开放区间。当前编辑的池高亮，改下架时间时线段当场伸缩。这条只在这页出现。

池子名：角色池 UP
开放：第 0 天
下架：第 21 天
单抽消耗：160
本 Banner 开放区间 天 0 → 84

高亮那条（角色池 UP）正被编辑；它和第 2 条的重叠区间一眼可见，这就是「池子互相抢时间」的地方。

D-B · 资源获取

页面内嵌累积资源曲线，台阶对应收入规则。只在这页出现，改周期或数量时曲线当场变陡/变平。

规则：every_n_days
数量：60
周期：1 天
起始资源：66420
累积资源（按当前规则推演） 120 天

规则是线性的，所以是直线；换成每周 +5 的规则，台阶就会显出来。

D-C · 保底机制

这页要的不是时间轴，而是出率随抽数变化的曲线（软保底递增 + 硬保底阈值）。它由 deltas 直接决定，是这一页唯一能一眼验证「我配的软保底对不对」的东西。

类型：soft_step
作用池：角色池 UP
阈值：90
计数器初始：0
出率曲线 抽数 1 → 90

曲线的拐点位置就是软保底起点；把它画出来，比在 deltas 表里数数字直观得多。

D-D · 累抽奖励

形态又是一样不同的东西：阈值尺。累抽奖励是一串离散阈值，画在抽数轴上，一眼看出分布与上限。

阈值：100
重复：是
上限：5 次
奖励：抽卡资源 ×30
阈值分布 累抽 0 → 600

蓝点是「重复」那条规则的 5 次触发（到上限为止），浅蓝点是单独一条不重复的规则。

D-E · 其余六页：没有预览，也不需要

卡牌定义 / 资源定义 / 抽卡策略 / 停止条件 / 目标卡 / 权重配置 / 满突溢出 这七页的内容没有时间维度，也不随参数连续变化，表格本身已经是最清楚的形态。给它们硬塞一块可视化只会占地方。这就是「各归各家」的直接结果：只有需要的那几页有，其余页面干净。
