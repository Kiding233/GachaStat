## 一、定义与边界

### 1.1 形式化

设被扫描参数为 θ ∈ Θ（一维），`Z = (Z₁, …, Z_n)` 为模拟产出的样本，`s(θ)` 为某统计量（GDR 均值、成功率、分位数等），`ŝ(θ)` 为其估计。

- **敏感性**：`ŝ` 关于 θ 的依赖结构
- **结论**：由 `ŝ(θ)` 派生的一元判定 `c(θ) ∈ {成立, 不成立}`。例：「成功率 ≥ 0.95」「A 一阶随机占优 B」「策略 X 排名第一」
- **翻转点** `θ*`：`c` 改变取值的 θ。一维、且 `c` 在 θ 上单调时是单点；非单调时是**多点集合**
- **裕度**：`|θ_当前 − θ*|`

**主诉求要注意**：「结论是否成立」只是 `c(θ)` 的一个读数。真正的诉求是 `ŝ(θ)` 的**形状与幅度**（§四），翻转点只是曲线穿过判据线的一个特例。把目标窄化成「找翻转点」会漏掉大半。

### 1.2 与近邻概念的边界

三者在日常语言里被混用，形式上的区别是**被扰动的是什么**：

| 概念 | 扰动对象 | 是否需要概率模型 |
|---|---|---|
| 敏感性 | 参数 θ 的取值（确定性） | 否，θ 取定值 |
| 稳健性 | 机制**假设** | 否，但被扰动的对象不是数值而是结构 |
| 不确定性 | 参数本身服从某分布 π(θ) | 是，需先给 π |

本计划只做敏感性。**U 系列（手册 §二十一 U1–U15）按敏感性处理**：它们在形式上是「两个互斥取值哪个对」，不引入先验分布，因此是二点扫描而非不确定性传播。真正的传播分析（给 π(θ) 后求 `c` 的成立概率）不在范围内。

> **一处易混**：`docs/架构设计.md` E3 写作「敏感性／稳健性分析」，P74 写「敏感度分析」，P87 写「敏感性分析」。同一件事三种叫法，本模块统一称敏感性分析。

## 二、两侧的统计性质不同（本计划的核心理论事实）

「需不需要重跑模拟」这条分界线不只是成本差异，它决定了两侧的统计结构，进而决定「信号与噪声」的判据不能共用一套。

### 2.1 复算侧：样本固定，差异即信号

同一批样本 `Z` 被反复消费，各扫描点的统计量是 `Z` 的**同一个确定性函数的取值**（除分析层自身的重采样，如 bootstrap）：

```
ŝ(θ_i) = f(Z, θ_i)
```

因此 `ŝ(θ_i) − ŝ(θ_j)` 中**不含抽样噪声**，只含：

1. θ 的真实效应
2. 分析层的重采样噪声（bootstrap、EVT 拟合等）

**推论**：复算侧不需要跨点检验就能读出「曲线动没动」。需要的是**量化每点自身的分析层噪声**，即每点的 CI。而且因为样本固定，各点之间是**完全配对**的，配对型检验可用。

注意其中还有一层细分：`gdr_threshold` 只在 `is_success()` 做后置比较、不进 `compute_gdr()`（`core/gdr.py:668-679`），所以扫它时各点的 `ŝ` 由**同一批中间量**归约而来，点间差异**纯粹**来自阈值本身；而三个权重进 `compute_gdr()`，各点要各自算一遍中间量，但样本仍相同。

### 2.2 派发侧：样本独立，差异 = 信号 + 噪声

每个扫描点 `θ_i` 抽出自己的一批样本 `Z^{(i)}`：

```
ŝ(θ_i) = f(Z^{(i)}, θ_i)
```

`ŝ(θ_i) − ŝ(θ_j)` 中含三部分：

1. θ 的真实效应（**要的信号**）
2. 两侧的抽样噪声（**要排除的**）
3. 两侧的分析层噪声（**要排除的**）

**推论**：派发侧**必须有跨点的检验**才能判定。而且两侧样本独立（`batch_simulator` 的并行路径用 `imap_unordered`，`aggregate_data` 按完成顺序排列，与 seed 顺序无关；`extract_aggregate` 产出的记录无 seed 字段），故**配对检验不可用**，只能用两样本方法。

### 2.3 同一种扫描参数归属不同侧

`card_weights`（`[[weights]]` 段）写在 config.toml 里，但只有 GDR 计算读它（`core/gdr.py:149/166`），所以它是**口径参数**，扫它不重跑。
而 `[[targets]]` 同时被两处读：策略读它决定追哪张卡（派发侧），GDR 读它决定测哪张卡（口径参数）。

**结论**：归属由「模拟器读不读」决定，不由「写在哪个文件里」决定。实现时不能按 TOML 段名分类。

### 2.4 派发侧的耦合与 CRN（已考虑，第一版不取）

§2.2 说派发侧「不配对」。理论上有办法让它**部分配对**：让第 k 次模拟在所有 θ 点上**共用同一个种子**（公共随机数，CRN）。这样「第 k 次这批模拟的运气」在各 θ 点之间是同一份，差分时抵消。

**收益**：曲线更平滑；同时置信带的临界值变小（正相关让各点一起偏，最大值不那么极端），带子更紧。

**为什么第一版不取**（2026-10-10 裁）：

1. **它改变区间读数的口径。** 把结果拆成三块：

   ```
   s_k(θ)  =  μ(θ)   +   ε_k   +   δ_k(θ)
              ↑          ↑          ↑
           要的信号   与 θ 无关   与 θ 交互
                    的运气      的偏差
   ```

   不用 CRN 时 `ε` 在差分中**不抵消**，区间回答「换一批模拟重跑，这个结论会变吗」（**含**运气）；用 CRN 时 `ε` **精确抵消**，区间回答「参数效应本身有多准」（**不含**运气）。两个都正当，但**不是同一个数**，不可混报。

2. **当前引擎撑不住。** `_run_single` 里 `random.seed(seed)` 之后，整条轨迹消费的是**全局单一顺序流**（`batch_simulator.py:519` → `pool.py:214/224` → `pity_tracker.py:393/400`）。一旦某个 θ 上的行为分歧导致**抽数不同**，此后两条流的偏移固定，后面的 u 完全对不上（梅森旋转不同状态等于独立）。所以耦合是**断崖式失效**，不是平滑衰减。只有里程碑走独立的 `random.Random(seed)`（`milestone.py:40`），不在全局流上。

**开 CRN 本身不用改引擎**：`run_batch_parallel(..., seed=S)` 的 `seed` 是形参（`batch_simulator.py:814`），把**同一个 S** 传给每个 θ 点即可（第 i 次模拟在所有 θ 上都是 `S + i`）。所以这不是「做不到」，是「口径上不取」。

**断崖位置按参数类型不同**（供将来恢复此选项时参考）：

| 参数类型 | 分歧机制 | 耦合能撑多久 |
|---|---|---|
| 甲类 口径参数 | 不重跑，同一批样本 | **完全配对**，CRN 无关 |
| 丙类 成本/资源 | 随机流不被触碰，只是资源耗尽时刻变 | **强耦合**，直到停止点才分岔 |
| 丙类 概率 | 同一个 u 可能映射到不同的卡 | 见下 |
| 乙类 策略参数 | 策略读它，动作序列可能变，抽数跟着变 | 看策略对参数的敏感度 |

**概率参数上的一条实读结论**：`pool.draw()` 是 `r = u * total_weight` 再 `bisect(cum_weights, r)`，对全池卡牌概率的**等比缩放**，bisect 保序，故**同一个 u 映射到同一张卡**，轨迹完全一致。这正好落在白名单「一组概率按比例整体缩放」的约束上（§七 待决项 B）。

**两个附带缺口（登记，不塞进 P90）**：

1. **引擎侧**：要做稳健版 CRN，需把顺序全局流换成**按抽数索引派生**（第 i 抽的 u 由 `hash(base_seed, i)` 得来），这样第 i 抽总取同一个 u，分歧不再污染后续。属 core 引擎改动（`pool.py` / `pity_tracker.py` 的抽样入口）。
2. **待实测核验**：「等比缩放 ⇒ 抽卡结果一致」只确证到 `pool.draw()` 的入口。喂给它的不是原始概率，而是经保底 `before_draw` 调整后的概率，而那个调整是**按稀有度槽位**做的非等比缩放（`banner.py:220-248`）。故保底未介入的抽上确证，保底触发（软保底爬升、硬保底、捕获明光）后映射会变，需实测。

## 三、翻转点是一个区间，不是一个点

### 3.1 不确定性来源

设结论形如 `c(θ) = [s(θ) ≥ τ]`。每个扫描点 `θ_i` 上，`ŝ(θ_i)` 带置信区间 `[L_i, U_i]`。于是该点的结论有三种状态：

| 状态 | 条件 | 含义 |
|---|---|---|
| 成立 | `L_i ≥ τ` | 置信区间整体在阈值上方 |
| 不成立 | `U_i < τ` | 整体在下方 |
| **说不准** | `L_i < τ ≤ U_i` | 区间跨过阈值 |

所以在采样网格上，「翻转」实际表现为：从「成立」经过一段**「说不准」地带**，再到「不成立」。

### 3.2 正确的输出形态

因此输出应当是**翻转区间**而非翻转点：

```
θ*_确定成立端  …  [ 说不准地带 ]  …  θ*_确定不成立端
```

「说不准地带」的宽度量级约为 `CI 半宽 / |ds/dθ|`。斜率越平坦，同样的 CI 宽度对应越宽的说不准地带；这也正是为什么**平坦区间上的结论对参数最敏感**（`ŝ` 变化慢，但不确定区间相对占比大）。

只报一个「翻转点」是虚假精确，与 P88 §3.5 判定的那类错误同源。

### 3.3 非单调与多点翻转

`c` 在 θ 上非单调时，翻转点是一个集合。此时「裕度」应取**最近的那个**翻转点。跳变（硬保底阈值、棋盘双态）会造成 `ŝ` 的阶跃，翻转点可能落在阶跃内部，且阶跃两侧的「说不准地带」形态与连续情形不同。

## 四、采样与细化的分工

| 手段 | 给出什么 | 决定因素 |
|---|---|---|
| 均匀采样（区间 + 步长） | **形状**：单调性、平台、跳变 | 步长决定能分辨的最小特征尺度 |
| 区间内二分 | **位置精度**：翻转点落在哪 | 容差决定分辨率 |

**步长必须小于机制的最小特征尺度**，否则会整段跳过跳变。本项目机制里跳变是常态（P26 核验报告实测 `p(r)` 是三级阶梯函数、第三跳跃达 35.0×SE；硬保底跳跃点；手册 G4 异环棋盘双态 1%→19.5%）。P26 Q2 的「几何锚定效应」正是**中点恰好击中跳跃点**导致二分收敛到错误侧，是该风险的实例。

**不用纯二分**：它假设单调性，遇跳变与多翻转会失效，且给不出形状。

**第一版不做自适应采样**：它按二阶差分决定下一点位置，适合预算紧的场景，但实现复杂、结果不可预期，且与「可复现」这一目标冲突（采样点依赖于运行时观测）。

## 五、结论判定的统计方法（待决项 A 的理论背景）

判据的选择由 §二 的配对性质决定，且**两侧不能共用**。2026-10-09 第二轮讨论后，本节定位从「在几个自拟候选里挑」改为「走向 dose-response 与有序备择检验的学界惯例」。

### 5.1 本问题在统计学里的归属

「沿一个有序轴取 N 个水平、每水平测响应、问响应怎么变、在哪里穿过阈值」是**剂量-响应（dose-response）分析**的标准形态。

**「反演」的统一名分：Fieller 型反演。** 核验确认（2026-10-10 第二轮）BMD / BMDL、Johnson-Neyman、ED50 逆置信限**是同一件事**：把置信区域与阈值线求交，反演出交点的置信集。SAS 明确把 `INVERSECL` 归到 **Fieller 定理**，理由是估计量是随机变量之比。这对本项目有直接好处：**P88 §3.5 已经为比值统计量采用 Fieller**，两处是同一套方法学，接得上。

**五条不是并列候选，是三层**（2026-10-10 核验后厘清）：

- **前提层：同时置信带。** 它不与其他条并列。反演要在整条曲线上找「带子穿过 τ 的位置」，若用逐点 CI 则每个点各判一次，族错误率按点数累积（§5.3）。**要反演就必须先有同时带。**
- **主线：反演置信带。** **BMD 与 Johnson-Neyman 在数学上是同一个操作**，只是阈值不同（BMD 用 BMR，J-N 用零线），输出都是**区间的边界**而非点。J-N 已被文献显式扩展到多项式/曲线情形。
- **补充层：对比类**（Williams / Dunnett），回答「哪些 θ 与基准显著不同」。
- **降级：Jonckheere-Terpstra**，为线性备择设计，见下表。

该文献里的既有答案：

| 需求 | 学界惯例 | 备注 |
|---|---|---|
| 曲线的整段陈述（「这段高于 τ」） | **同时置信带**（simultaneous confidence band）：覆盖整条曲线、概率 1−α 的带子 | 与「点级 CI」不是一回事。用点级做整段陈述会让实际覆盖率远低于名义水平 |
| 「哪几个水平与基准显著不同」 | **Dunnett**（不要求次序，各水平 vs 对照，控制族错误率）；**Williams' test**（要求单调） | **Williams 假设单调剂量响应，且是单侧 step-down，逆向波动被「视为偶然」而合并相邻组**，故与 PAVA 同挂单调门。Dunnett 不利用次序，是无条件可用的那条。单调成立时 Williams 功效显著高于 Dunnett |
| 「有没有单调趋势」 | **Jonckheere-Terpstra** | 验的是趋势，不是翻转。**且它与 Cochran-Armitage 都是为线性备择设计的，有平台期时损失功效**（文献直说「很少真的想精确检验线性趋势」），本项目曲线常带平台与跳变，故降级为形状判定辅助 |
| 「响应在哪个剂量穿过阈值」（含不确定区间） | **BMD / BMDL**（benchmark dose 及其置信下限） | 毒理与风险评估的标准量，EFSA / US EPA 有指南 |
| 「θ 落在哪些区间时结论成立」 | **Johnson-Neyman 技术**（调节效应分析） | 非单调时给多个边界，区间可以**不相交** |
| 「使响应达到某水平的剂量」（含区间） | **ED50 逆置信限**（SAS PROC PROBIT `INVERSECL`） | 明说由 **Fieller 定理**算得，理由是估计量是**随机变量之比** |

### 5.2 已否决的做法

**「各点 CI 是否重叠」不能当判据。** 两个独立估计各自的 95% CI 重叠，**不蕴含**它们的差在 5% 水平上不显著（反向蕴含成立：不重叠确实蕴含显著）。用它当判据会系统性地把真差异判成噪声。具体到本项目更糟：n=1000 时成功率的 CI 半宽约 1.6 个百分点，相邻扫描点的 CI 大概率重叠，曲线会看着全是平的。

**核验到的定量事实**（来源见 §5.5）：等方差且两估计独立时，**两个 95% CI 不重叠在零假设下的概率只有 0.0056**，不是 0.05。也就是说重叠是比名义水平**严格约十倍**的判据。文献给的正确做法是**对差值本身算 CI**；若坚持用「区间是否重叠」作图，需把区间收窄到 **83.4%**（等方差独立时）并明确标注该百分比，否则读者仍会按 95% 读。

### 5.3 一个必须注意的陷阱

反复用同一批数据做多次比较（N 个扫描点两两比、或与阈值比）会累积第一类错误。若按每点独立判定的口径报「显著」，实际错误率远高于名义水平。这与 P88 §3.5 的问题同源（那里的具体表现是朴素二项 CI 低估方差 39 到 131 倍，实测值）。标准处置**不是**事后校正，而是同时带或有序备择检验（§5.1）。这也是为什么同时带是**前提层**：反演在逐点 CI 上做，等于把 §5.3 这个陷阱原样搬进主线。

### 5.4 收敛结果（2026-10-10）

**已定案**：同时带（前提）＋ 反演（主线，非参数实现）＋ Williams/Dunnett（补充），Jonckheere-Terpstra 降为可选辅助。见计划 §七 待决项 A 与 §八 第 22b、22c 条。

**补充层要再分**：Williams「假设单调剂量响应关系」，与 PAVA 同一个问题，故**与 PAVA 同挂「用户显式声明单调」的门**；**Dunnett 不要求次序，无条件可用**。

同一轮另裁两项：

- **翻转区间报双侧**（计划 §八 第 24 条）：两个交点都报。BMDL 的单侧形态是监管需求，本项目不是监管。
- **CRN 默认不启用**（第 25 条）：理由见本文件 §2.4。

**别照搬 dose-response 的三点**：① 模拟器**可无限采样**，BMD 那套参数模型拟合与模型选择可整个跳过，直接走非参数；② 响应是模拟出来的，各点噪声原则上可用 CRN 压低（第一版不取）；③ BMD 是单调世界（剂量增风险增），本项目响应可能增也可能减、还可能非单调，文献的单调前提普遍不成立。

### 5.6 反演的一个必知病理：置信集未必是个区间

反演不是「求两个交点、取中间」这么干净。**Fieller 型置信集的形态由判别式决定**，已知分类至少含：

| 形态 | 含义 | 怎么来的 |
|---|---|---|
| **有界区间** | 正常情形，报 `[lo, hi]` | 判别式 > 0 且分母远离 0 |
| **补集形态**（不连通） | 「除了中间这段，其余都行」 | 判别式 > 0 但置信椭圆不覆盖原点 |
| **无界**（半轴或全直线） | 「推不出上界」 | `a < 0`（分母的置信区间包含 0） |
| **空集** | 「这批数据与任何取值都不相容」 | SAS 文档所谓「虚根」或「所有点都在区间之外」 |

**对本项目的直接要求**：不能假设反演一定给出一个闭区间。实现里要**判形态并如实报**（例如报「本参数方向上翻转点无上界」而非硬给一个数），图上也要有对应的表达（半轴开口、断开着色）。

这与 P88 §3.5 的处置同源：那里遇到比值统计量的 CI 不可靠，最稳妥是只报两个分量各自的 CI。此处同理，**形态异常时退回到「只报曲线的带子，让读者自己看交点」也是可接受的降级**。

## 八、曲线工具的复用清点

见计划 §3.7.1 的逐件表与 §3.8b 的提取方案。要点：

- 复用是**方法与输出契约**层面的，不是实现照搬。根本差异：脆弱性的 x 轴是**样本内变量**（n 个 `(x, y)` 原始对），敏感性的 x 轴是**数据集间标签**（N 个点估计 ＋ 各自 CI）。
- `_find_contiguous_intervals_from_curve`（`:805`）/ `_wilson_ci`（`:175`）/ `_diagnose_monotonicity`（`:203`）**零领域知识，可直接搬**。
- `_changepoint_ci`（`:278`）**搬方法与输出契约、换输入**：它现在 bootstrap 的是「重采 `(r_i, y_i)` → 固定箱边界重新计数 → PAVA」，敏感性侧没有箱内样本对。输出契约（`x_star_pt` / `x_star_lo` / `x_star_hi`）两边相同。
- `binsglm` 分箱**看密度**：稀疏扫描（用户指定网格，N=10~20）不适用；高密度（N 数百）适用，且其 `cb=True` 提供同时置信带，而 `vulnerability.py:373` 把 `cb` 关掉了（`ci=False, cb=False`）。注意 `binsglm` **本身是非保序**的分箱平滑器。

### 8.0 单调假设：脆弱性的前提，敏感性的待验结论

脆弱性的 H4 是「单调递减（**强制**）」，依据是经济直觉（资源越多失败率越低）；PAVA 是它**额外加的一层约束**，不是分箱自带的。敏感性分析的**主诉求恰恰是问单调与否**（形状判定），所以默认套 PAVA 是**循环论证**。

- **默认路径不保序**：逐点估计 ＋ 区间，或（高密度）`binsglm` 非保序平滑 ＋ `cb` 带。
- PAVA 只在用户**显式声明**单调、或作**对照**（「若强制单调，曲线会怎样」）时使用。
- `_changepoint_ci` 算的是 PAVA 拟合曲线的变更点，故继承同一前提。

**按扫描类型分开**（2026-10-10 补）：

| 扫描类型 | 单调性 | PAVA |
|---|---|---|
| **阈值型**（扫判据 τ） | `ŝ(τ) = P(s ≥ τ)` 关于 τ **必然递减**，由集合收缩保证（τ 增大则 `{s ≥ τ}` 收缩），是**结构性事实而非假设** | 可用且正当（分箱后的微小逆向波动该修） |
| **非阈值型**（扫池子成本等） | 待验 | 默认不用（循环论证） |

这是「区分事实与结构保证」的一个实例：同样是「曲线单调」，阈值型下是**由构造保证的**，非阈值型下是**由数据回答的**。两者不能共用一句「默认不保序」。

**两种「合并」要分清**：分位数分箱**不合并**（只定边界，箱数由 `binsmethod='dpi'` 数据驱动选出）；**PAVA 会合并**相邻的逆向波动。敏感性侧的 θ 点是用户选的**设计点**（θ=0.90 与 0.91 是两个真问题），合并会藏掉用户想看的差异——这是「默认不保序」的第二个理由。

### 8.1 三行子图的语法对照

行的语义是「① 支撑情况 → ② 推断主图 → ③ 每点可靠性」。第②行**逐元素同构**，①③ 只是语义对应：

| 行 | 脆弱性分析 | 敏感性分析（拟） |
|---|---|---|
| ① | 等距直方图（样本在资源轴上的分布） | 与判据直接相关的**样本内变量**的分布（阈值型扫描下即响应值 `s_k`），并把判据线画上去 |
| ② | p̂ 散点（∝ `N_j`）＋ PAVA 台阶 ＋ α 线 ＋ 脆弱区间着色 ＋ 变更点 CI 带 | 响应曲线 ＋ 误差带 ＋ τ 线 ＋ 成立域着色 ＋ 翻转区间 CI 带 |
| ③ | 每箱样本量 `N_j`（分位数分箱下接近常数，信息在柱宽与配色） | 每点 CI 宽度（等样本量下 `N_j` 恒定，故换量占位） |
