### Task 2: binsglm 分箱 + PAVA + 变更点推断（问题 D/E/F/G 一体化修复）

**Files:**
- Modify: `gacha_simulator/core/vulnerability.py`
- Test: `tests/core/test_vulnerability.py`（追加测试）
- Dependency: `binsreg` (PyPI, 已验证 ✅)

**现状：** `_fit_local_polynomial` 使用局部逻辑回归在 200 个格点上估计光滑 P(失败|r) 曲线。存在四个理论缺陷——带宽选择无最优性（D）、无多重性校正（E）、格点噪声（F）、均匀带宽不适应数据密度（G）。

**新方案：三阶段管线**

```
资源数据 (r_i, y_i)
       │
       ▼
① binsglm 分位数分箱 ──── 只取 dots.fit + data_bin 边界
   │  IMSE 选 J（工程启发式，非理论最优）
   │  输出: x_left, x_right, p̂_j, N_j
       │
       ▼
② PAVA 保序估计 ──── 单调递减约束下合并逆向波动
   │  输出: θ̃_j, blocks, theta_tilde_per_bin
   │
   ├── 单调性诊断 ──── 检测策略断点
   │   若断点存在 → 局部回退独立检验 + Sidak
   │
       ▼
③ 变更点估计 ──── ĵ* = max{j: θ̃_j > α}
   │  Bootstrap CI（固定箱边界）→ [ĵ*_lo, ĵ*_hi]
   │  输出: 脆弱区间右界（点估计 + 保守/乐观端）
```

**与旧方案（Wilson CI + Sidak）的核心区别：**

| | v3 混合方案 | v4 PAVA + 变更点 |
|---|---|---|
| 推断问题 | J 个独立检验 | 1 个变更点估计 |
| 多重性处理 | Sidak 校正 (O(J) 成本) | 变更点 CI (O(1) 成本) |
| 结构假设 | 无 | 单调递减（可检验、可回退） |
| 采样逆向波动 | 独立判定 → 可能断裂区间 | PAVA 自动吸收 → 区间强制连续 |
| 对 N_j 小的箱 | Wilson CI 变宽 → 丢失 | 被相邻箱合并 → 共享信息 |

```python
# gacha_simulator/core/vulnerability.py

def _pava(p, w):
    """Pool Adjacent Violators Algorithm——保序回归（递减约束）。

    Args:
        p: 原始比例估计 (length J)
        w: 权重（= N_j，每箱样本数）

    Returns:
        theta: 保序估计 (length L ≤ J)
        w_out: 块权重 (length L)
        blocks: 块结构 list of list，blocks[i] = 该块包含的原始箱索引
    """
    p = np.asarray(p, dtype=float)
    w = np.asarray(w, dtype=float)
    J = len(p)
    blocks = [[i] for i in range(J)]
    current_p = p.copy()
    current_w = w.copy()

    changed = True
    while changed:
        changed = False
        i = 1
        while i < len(current_p):
            if current_p[i - 1] < current_p[i]:  # 违反递减
                K_pool = (current_p[i - 1] * current_w[i - 1] +
                          current_p[i] * current_w[i])
                w_pool = current_w[i - 1] + current_w[i]
                current_p[i - 1] = K_pool / w_pool
                current_w[i - 1] = w_pool
                blocks[i - 1].extend(blocks[i])
                current_p = np.delete(current_p, i)
                current_w = np.delete(current_w, i)
                del blocks[i]
                changed = True
                break  # 回溯
            i += 1
    return current_p, current_w, blocks
```

先实现 Wilson score interval（在 `_diagnose_monotonicity` 中替代 Wald SE）：

```python
def _wilson_ci(n_success, n_total, level=0.95):
    """Wilson score 置信区间——不对 p̂=0 或 p̂=1 塌缩。"""
    from scipy.stats import norm
    if n_total == 0:
        return 0.0, 1.0
    z = norm.ppf(1 - (1 - level) / 2)
    p_hat_val = n_success / n_total
    denom = 1 + z**2 / n_total
    center = (p_hat_val + z**2 / (2 * n_total)) / denom
    margin = z * np.sqrt(
        p_hat_val * (1 - p_hat_val) / n_total + z**2 / (4 * n_total**2)
    ) / denom
    return center - margin, center + margin
```

然后实现单调性诊断，用 Wilson SE 而非 Wald SE：

```python
def _diagnose_monotonicity(p_hat, N_j, x_left, x_right):
    """诊断单调递减假设是否被策略断点违反。

    检查每对相邻箱的逆向波动幅度是否超过采样噪声能解释的范围。
    使用 Wilson SE（不对 p̂=0/1 塌缩），而非 Wald SE。

    REVIEW-R1-FIX: ISSUE-008
    注意：SE_j = (hi_j - lo_j) / (2 * 1.96) 是 Wilson CI 半宽的近似。
    Wilson score interval 在 p̂ 接近 0 或 1 时不对称——半宽除以标准正态分位数
    仅近似标准误，非精确值。对于 N_j 很小且 p̂ 极端的箱，此近似可能低估噪声尺度。
    若需要精确 SE，使用 Wilson 方差公式：
    var = p̂(1-p̂)/(n+z²) * n/(n+z²)。

    Returns:
        breakpoints: list of dict(j, x_boundary, diff, noise_scale, severity)
        monotonicity_holds: bool —— True 表示无断点，单调性成立
    """
    # REVIEW-R1-FIX: ISSUE-006 同模块内直接调用 _wilson_ci，无需 import
    J = len(p_hat)
    breakpoints = []

    for j in range(J - 1):
        if p_hat[j] < p_hat[j + 1]:  # 逆向波动
            diff = p_hat[j + 1] - p_hat[j]
            # Wilson SE：p̂=0 时也不塌缩
            lo_j, hi_j = _wilson_ci(
                int(round(p_hat[j] * N_j[j])), N_j[j], level=0.95)
            lo_j1, hi_j1 = _wilson_ci(
                int(round(p_hat[j + 1] * N_j[j + 1])), N_j[j + 1], level=0.95)
            # 用 Wilson CI 半宽近似 SE
            se_j = (hi_j - lo_j) / (2 * 1.96) if N_j[j] > 0 else 1.0
            se_j1 = (hi_j1 - lo_j1) / (2 * 1.96) if N_j[j + 1] > 0 else 1.0
            noise_scale = np.sqrt(se_j**2 + se_j1**2)

            if diff > 3 * noise_scale:
                severity = 'breakpoint'
            elif diff > 1.5 * noise_scale:
                severity = 'suspicious'
            else:
                severity = 'noise'

            breakpoints.append({
                'j': j,
                'x_boundary': x_left[j + 1],
                'diff': diff,
                'noise_scale': noise_scale,
                'severity': severity,
            })

    has_breakpoint = any(bp['severity'] == 'breakpoint' for bp in breakpoints)
    return breakpoints, not has_breakpoint
```

```python
def _changepoint_ci(x_left, x_right, p_hat, N_j, r, y,
                    alpha=0.5, gamma=0.05, n_boot=500,
                    theta_tilde=None, blocks=None, seed=None):
    """Bootstrap 变更点置信区间（在固定箱边界下）。

    重采样 (r_i, y_i) 对 → 固定边界上重新计数 → PAVA → ĵ*_b。
    ĵ* 的 (1−γ) 置信集 = 覆盖 (1−γ) 比例 ĵ*_b 的连续索引范围。

    Args:
        theta_tilde, blocks: 可选，预计算的 PAVA 输出。
            若调用方已在 _fit_vulnerability_pava 中跑过 PAVA，
            传入此参数可避免重复计算。
        seed: 可选，Bootstrap 随机种子。传入固定 int 可复现结果（测试必需）。

    Returns:
        dict with: j_star, j_star_lo, j_star_hi,
                   x_star_pt, x_star_lo, x_star_hi
    """
    # _pava 定义在同一模块中，直接调用，无需 import
    J = len(p_hat)
    n = len(r)
    rng = np.random.default_rng(seed)  # REVIEW-R1-FIX: ISSUE-002 种子化保证可复现

    # 点估计——若调用方已传 PAVA 结果则直接复用
    if theta_tilde is None or blocks is None:
        theta_tilde, _, blocks = _pava(p_hat, N_j)
    theta_per_bin = np.zeros(J)
    for bi, blk in enumerate(blocks):
        for j in blk:
            theta_per_bin[j] = theta_tilde[bi]
    j_star = max((j for j in range(J) if theta_per_bin[j] > alpha), default=None)

    # Bootstrap
    j_star_boot = []
    for _ in range(n_boot):
        idx = rng.choice(n, size=n, replace=True)
        r_b, y_b = r[idx], y[idx]
        p_b = np.zeros(J)
        for j in range(J):
            mask = (r_b >= x_left[j]) & (r_b < x_right[j])
            if j == J - 1:
                mask = (r_b >= x_left[j])
            nj = mask.sum()
            p_b[j] = y_b[mask].sum() / nj if nj > 0 else 0.0
        theta_b, _, blocks_b = _pava(p_b, N_j)
        theta_per_b = np.zeros(J)
        for bi, blk in enumerate(blocks_b):
            for j in blk:
                theta_per_b[j] = theta_b[bi]
        js = max((j for j in range(J) if theta_per_b[j] > alpha), default=None)
        if js is not None:
            j_star_boot.append(js)

    if j_star_boot:
        j_star_lo = int(np.percentile(j_star_boot, 100 * gamma / 2))
        j_star_hi = int(np.percentile(j_star_boot, 100 * (1 - gamma / 2)))
    else:
        j_star_lo = j_star_hi = 0

    return {
        'j_star': j_star,
        'j_star_lo': j_star_lo,
        'j_star_hi': j_star_hi,
        'x_star_pt': x_right[j_star] if j_star is not None else None,
        'x_star_lo': x_left[max(0, j_star_lo)],
        'x_star_hi': x_right[min(J - 1, j_star_hi)],
    }
```

```python
def _fit_vulnerability_pava(resource_arr, failure_arr, alpha=0.5, gamma=0.05):
    """三阶段管线：binsglm 分箱 → PAVA 保序 → 变更点 CI。

    替代 _fit_local_polynomial()。
    回退路径：binsglm 失败 → _logistic_ll_fit + 曲线走查（旧方法）。
    """
    import logging
    import traceback
    from binsreg import binsglm

    x = np.asarray(resource_arr, dtype=np.float64)
    y = np.asarray(failure_arr, dtype=np.float64)

    try:
        # ① binsglm 分位数分箱
        result = binsglm(y, x, dist='Binomial', noplot=True, ci=False, cb=False)
        dp = result.data_plot[0]
        J = len(dp.dots)
        x_left = dp.data_bin['left_endpoint'].values.astype(float)
        x_right = dp.data_bin['right.endpoint'].values.astype(float)
        x_center = dp.dots['x'].values.astype(float)
        p_hat = dp.dots['fit'].values.astype(float)
        N_j = dp.dots['n'].values.astype(int)
        K_j = (p_hat * N_j).round().astype(int)

        # ② PAVA 保序估计
        theta_tilde, w_tilde, blocks = _pava(p_hat, N_j)
        theta_per_bin = np.zeros(J)
        for bi, blk in enumerate(blocks):
            for j in blk:
                theta_per_bin[j] = theta_tilde[bi]

        # 单调性诊断
        breakpoints, monotonicity_holds = _diagnose_monotonicity(
            p_hat, N_j, x_left, x_right)

        # ③ 变更点 CI（传入预计算 PAVA，避免重复）
        cp = _changepoint_ci(x_left, x_right, p_hat, N_j, x, y,
                             alpha=alpha, gamma=gamma,
                             theta_tilde=theta_tilde, blocks=blocks)

        # 脆弱区间
        vulnerability_intervals = []
        if cp['j_star'] is not None:
            vuln_right = cp['x_star_hi']
            vulnerability_intervals.append({
                'lower': float(x_left[0]),
                'upper': vuln_right,
                'right_edge_point': float(cp['x_star_pt']),
                'right_edge_lo': float(cp['x_star_lo']),
                'right_edge_hi': float(cp['x_star_hi']),
                'lower_at_data_boundary': x_left[0] > 1e-9,
            })

        return {
            'bin_centers': x_center,
            'bin_edges': list(zip(x_left, x_right)),
            'x_left': x_left,
            'x_right': x_right,
            'p_hat': p_hat,
            'N_j': N_j,
            'K_j': K_j,
            'theta_tilde': theta_tilde,
            'theta_per_bin': theta_per_bin,
            'blocks': blocks,
            'vulnerability_intervals': vulnerability_intervals,
            'changepoint': cp,
            'breakpoints': breakpoints,
            'monotonicity_holds': monotonicity_holds,
            'used_fallback': False,
        }

    except Exception:
        logging.warning(
            f"binsglm/PAVA 管线失败，回退到局部逻辑回归:\n"
            f"{traceback.format_exc()}"
        )
        # 回退路径：旧方法 _logistic_ll_fit + 曲线走查
        n = len(x)
        sigma = float(np.std(x))
        h = 1.06 * sigma * (n ** (-0.2))
        h = max(h, (float(x.max()) - float(x.min())) / max(n, 1) * 2)
        r_grid = np.linspace(x.min(), x.max(), 200)
        lp_curve = _logistic_ll_fit(x, y, r_grid, h)
        lp_curve = np.clip(lp_curve, 0.0, 1.0)

        # 旧版曲线走查法提取脆弱区间
        vuln_mask = lp_curve > alpha
        vuln_intervals = []
        if np.any(vuln_mask):
            vuln_intervals = _find_contiguous_intervals_from_curve(
                vuln_mask, r_grid, x, y, lp_curve)
            vuln_intervals = [
                {'lower': vi.lower, 'upper': vi.upper} for vi in vuln_intervals
            ]

        return {
            'bin_centers': r_grid,
            'bin_edges': [],
            'x_left': np.array([r_grid[0]]),
            'x_right': np.array([r_grid[-1]]),
            'p_hat': lp_curve,
            'N_j': np.ones(len(r_grid), dtype=int),
            'K_j': (lp_curve).round().astype(int),
            'theta_tilde': lp_curve,
            'theta_per_bin': lp_curve,
            'blocks': [[i] for i in range(len(r_grid))],
            'vulnerability_intervals': vuln_intervals,
            'changepoint': {
                'j_star': None, 'j_star_lo': 0, 'j_star_hi': 0,
                'x_star_pt': None, 'x_star_lo': 0.0, 'x_star_hi': 0.0,
            },
            'breakpoints': [],
            'monotonicity_holds': True,
            'used_fallback': True,
        }
```

## 风险与缓解

| 风险 | 概率 | 影响 | 缓解措施 |
|------|------|------|---------|
| `binsreg` SVD 崩溃波及分箱功能 | 低 | 高 | 已验证分箱（`ci=False, cb=False`）不经过 SVD 路径，稳定 |
| PAVA 在策略断点处错误合并 → 偏差 | 中 | 中 | 单调性诊断检测断点 → 局部回退独立检验；PAVA 只在违反处合并 |
| Bootstrap 变更点 CI 计算成本高（n_boot=500 × binsglm） | 高 | 低 | 变更点 CI 在固定箱边界上重采样——不重新调 binsglm，仅重新计数 + PAVA（~10ms/boot） |
| 单调递减假设被用户策略频繁违反 | 低 | 高 | 诊断自动检测 → 全局回退独立检验 + Sidak（等价 v3 方案）；UI 标注「单调性不适用」 |
| 硬保底边界处 θ(r) 的真实跳跃被 PAVA 平滑 | 高 | 低 | 跳跃不改变单调方向——PAVA 不会在对立方向上合并它。变更点偏移 ≤ 1 箱宽 |
| 现有测试依赖 `_fit_local_polynomial` | 低 | 中 | T2 修改 mock/期望值 |
