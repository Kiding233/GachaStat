> 标注：【保留】= 现状合理，直接迁移；【重设计】= 借换头重新设计；【待裁决】= 跨面板用法分歧，需统一规范。

## 一、组件映射（按类别）

### 1. 表格类

| Qt 组件（频次） | 典型用法 | Element Plus 映射 | 映射注意点 |
|---|---|---|---|
| QTableWidget（57/41）【待裁决】 | 展示表一律 NoEditTriggers 只读；config_panel 用 setCellWidget 内联编辑（概率 spin/稀有度 combo/Featured check/资源串 input）；唯一允许 item 编辑的 dist_table；全程无排序；选择模式 SelectRows/Extended/Single/No 四种并存 | el-table + :data + column prop | **可编辑性两极分化需裁决**：Vue 统一方案为「el-table 默认只读 + 需要编辑的列用 slot 内联 el-input-number/el-select/el-checkbox」。选择模式：SelectRows→highlight-current-row；Extended→@selection-change + type=selection 列。无排序→el-table sortable 可顺势补（行为增强） |

| QHeaderView（100） | 列宽三态：Stretch（弹性）/ Fixed（序号/勾选/短数值）/ ResizeToContents（文本）；无排序点击 | el-table-column width / min-width / 自适应 | Stretch→不设 width 自动分配；Fixed→设 width；ResizeToContents→min-width + show-overflow-tooltip。隐藏行号 el-table 天然无。斑马纹 setAlternatingRowColors→stripe |
| QListWidget（8/11）【待裁决】 | config_panel 7 处：banner_list 是 Master 侧（currentRowChanged 驱动详情 + 行内 checkbox 启用 + setHidden 过滤）；其余仅展示/单选 | el-menu / el-table 单选列 / el-select | Master 列表→el-menu（高亮当前）+ 行前 el-checkbox（或 el-table 单选列）；setHidden 过滤→computed filter（非 DOM 删改）。**与 QComboBox 的选择交互需统一**（见裁决点 5） |

## 二、复合机制映射

| 机制 | Qt 现状 | Element Plus 方案 | 判定 |
|---|---|---|---|
| A1 Master-Detail（config 卡池 Tab） | QListWidget Master + QGroupBox 详情表单（空选禁用）+ 池/生命周期子 Tab + 防抖保存 | el-menu（Master）+ el-form 详情（空选禁用）+ el-tabs（子）+ 防抖 | 【保留】核心交互模式，数据流用 Vue 响应式改写 |
| A2 参数区 + 图表区（全分析面板标准结构） | QSplitter = 左 ScrollArea 参数组 + 右 结果区；比例 左250-420/右700-920 | el-row/el-col（或手写分栏）+ 参数卡 + ECharts 区 | 【保留】最同构的布局，10 面板统一 |
| A4 配置自动更新数据流（config_panel）【重设计】 | 编辑控件 valueChanged → 防抖 QTimer(500ms) → config_changed 信号 → main_window 刷新 ConfigStore → 其他面板读 store | 前端响应式状态为主（v-model 即时反馈）→ watch+debounce(500ms) → js_api 写回 Python ConfigStore（兼容「编辑即同步」语义） | 【重设计】Vue 响应式天然支持，但需裁决：Python ConfigStore 是否仍为单一真相源（建议：前端为主 + 防抖写回，减少高频跨桥） |
| 运行按钮生命周期 | setEnabled(False) 启动 → finish/error 恢复 | el-button :loading | 【保留】更优雅，按钮文字不变 |
| 语义色体系 | 绿=主操作/蓝=图表系列/红=危险/深绿=显著/灰=次级 | design tokens（见五） | 【保留】迁移为 tokens |
| 异步 worker 契约 | finished/progress/error 三信号 + status_update 桥接 | Promise + 进度回调 + 状态管理 | 【保留】链路已验证 |
| 表单校验 | 全后置（保存/提交时 validate + QMessageBox） | el-form rules 即时校验 | 【重设计】前移校验时机 |
| 只读表格 | NoEditTriggers + 中文列头 + 隐藏行号 + 状态色 | el-table 默认 + 列配置 | 【保留】 |

## 三、迁移裁决点（跨面板分歧 → 需定规范）

1. **运行按钮主色**：绿 #4CAF50（analysis/plan_search）vs 蓝 #1976d2（comparison/data_manager）vs 无样式（gacha/retreat 等）→ 定「主操作色」规范
2. **可编辑表格策略**：只读 vs item 编辑 vs setCellWidget 内联 → 统一为「el-table 只读 + 需编辑列 slot 内联控件」
3. **表格排序**：全项目 0 处 → el-table sortable 顺势补（增强）
4. **进度显示**：常驻 vs 运行中显示 vs (done,total) 不同步 → 统一
5. **选择交互**：QListWidget（config Master）vs QComboBox（其余）→ 定两种选择场景的对应组件
6. **时间输入**：唯一 QDateEdit（日期）vs 浮点天 spinbox → 定数据模型（建议统一为日期或明确浮点天语义）
7. **校验时机**：后置 vs 即时 → 建议 el-form 即时校验
8. **按钮反馈**：文字突变 vs 仅禁用 → 统一 :loading
9. **状态展示**：面板内 QLabel vs 全局 QStatusBar → 统一
10. **图表色板**：comparison Tableau 10 vs 其余单色 #2196F3/#4CAF50 → 定全局图表色板 tokens
