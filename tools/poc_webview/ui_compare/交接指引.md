## 1. 任务一句话

为统计工具 GachaStat 设计一套**现代、统一、可复用**的 UI 设计规范（含 design tokens 与演示页面），支撑从 PyQt6 迁移到 Web 前端。技术选型已定，**设计规范尚未定稿，10 个裁决点待裁决**。

## 2. 技术栈与运行

| 项 | 值 |
|----|-----|
| 窗口容器 | pywebview（系统 WebView2，不捆绑内核，Python 主进程） |
| 前端 | Vue 3（组合式 API，`<script setup>`） |
| 组件库 | Element Plus（已选定） |
| 图表库 | ECharts（已选定） |
| 构建 | Vite（热重载） |

**运行演示页**（本目录下）：
```
python load_compare.py
```
自动拉起 Vite + 打开窗口；改 `src/` 下文件实时热更新。

## 4. 已确定约束（详细在交接文档 §3，这里摘要）

1. 技术选型 pywebview + Vue3 + Element Plus + ECharts，不可改
2. 统计工具定位：密集信息 + 语义色强调结果
3. 中文界面，中文字体 Microsoft YaHei / PingFang SC
4. **视觉方向：黑白灰骨架 + 彩色语义点缀**（蓝/绿/红/黄只做语义）；结构感靠色块层次 + 轻阴影，不用硬边框
5. 无内容切换动画；切换反馈体现在 Tab 行样式（悬停整体变灰）
6. 界面结构：顶部工具栏 + 内容 Tab 区 + 底部状态栏
7. 主操作色蓝色系（当前 #1976d2，可微调）
8. A4 配置自动更新：前端响应式 + 防抖写回 Python
9. 布局对齐现有 Qt（Master-Detail、参数区 + 图表区、QGroupBox 分区）

> 注意：两版视觉（绿系、黑白灰+色块）用户均不完全满意，**当前视觉是中间态，不是最终**。上面 1-9 是方向约束，具体视觉方案由设计 harness 产出并交用户验收。

## 5. 待裁决设计点（工作核心，10 个）

1. 运行按钮主色（Qt 三套并存：绿/蓝/无）→ 统一。当前方向蓝色系
2. 可编辑表格策略（只读 vs item 编辑 vs 内联控件）→ 建议 el-table 只读 + 需编辑列 slot 内联控件
3. 表格排序（Qt 全项目 0 处）→ 是否补 el-table sortable
4. 进度显示（常驻 vs 运行中显示 vs done/total）→ 统一
5. 选择交互（QListWidget Master 列表 vs QComboBox）→ 两种场景对应组件
6. 时间数据模型（唯一日期控件 vs 浮点天 spinbox）→ 统一
7. 表单校验时机（Qt 后置 vs el-form 即时）→ 建议前移
8. 按钮反馈（Qt 文字突变 vs 仅禁用）→ 统一为 :loading
9. 状态展示（面板内 QLabel vs 全局状态栏）→ 统一
10. 图表色板（comparison Tableau 10 vs 其余单色）→ 全局图表色板规范

## 6. 建议工作流

1. 读 §3 必读两份材料（交接文档 + 组件对照表）
2. 运行演示页（§2 命令）看当前 config 面板与视觉
3. 逐条裁决 §5 的 10 个点（结合演示页实际效果），记录裁决理由
4. 落实：改 `src/styles/tokens.css`（tokens）+ 逐面板调视觉（App.vue / ConfigPanel.vue，补 analysis/plan_search/comparison 面板）
5. 每轮改动用 load_compare.py 查看，交用户确认视觉与裁决点
6. 定稿产出：`docs/00-meta/UI设计体系/UI设计规范.md`（tokens 表 + 组件/布局/图表/交互规范 + 10 点裁决）+ `src/styles/tokens.css` 定稿

## 7. 产出物要求

1. **UI 设计规范文件**（`docs/00-meta/UI设计体系/UI设计规范.md`）：design tokens 表、组件规范、布局规范、图表规范、交互规范、10 点裁决
2. **tokens.css 定稿**（`src/styles/tokens.css`，前端直接消费）
3. **演示页补全**：analysis / plan_search / comparison 面板纯 UI（假数据），覆盖全部待测组件，作为规范可视化载体

## 8. 边界（不越界）

- 不动 `gacha_simulator/core`、`service`、`cli`（计算引擎，~800 测试锚点）
- 不接 Python 逻辑（阶段 1b 的事）；演示页用假数据
- 不改技术选型（pywebview / Vue3 / Element Plus / ECharts）
- 行为等价要求（同配置同种子模拟结果一致）是最终迁移验收线，设计不破坏它
