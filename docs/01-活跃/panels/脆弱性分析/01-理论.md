> 建档日期：2026-06-08 | 版本：v3.0（P51 离散分箱 + PAVA + 变更点推断——完全替换核回归）
> 理论审核来源：P15（9 项缺陷，A-C 阶段一已修复）+ P51（D/E/F/G 离散分箱框架一体化修复）

## 一、核心假设

| 假设 | 内容 | 成立条件 |
|------|------|---------|
| H1: 离散分箱充分性 | binsglm 分位数分箱（~J 箱）能够充分捕捉 θ(r) = P(失败\|资源=r) 在资源域上的变化 | J 足够大（IMSE 自动选择）；箱内 θ(r) 近似常数 |
| H2: 二元响应 | 每次模拟产出二值结局（成功/失败），由 GDR 阈值判定 | 阈值选择合理；GDR 指标恰当 |
| H3: 条件独立性 | 给定资源 r，各次模拟的失败判定独立 | 模拟间独立（不同 seed 保证）；但同一模拟内多池不独立 |
| H4: 单调递减（强制 + 可回退） | P(失败\|r) 随 r 递减——资源越多失败概率越低 | 经济直觉支撑；PAVA 在估计中强制执行；策略断点由诊断检测并局部回退 |
| H5: 设计点视为固定 | 将资源观测值视为固定设计点（design points），忽略其随机性 | 资源值本身是随机的（抽样变异），当前将其视为固定协变量，可能引入 Berkson 误差 |
| H6: 变更点存在性 | 存在唯一临界资源值 r*，使得 r < r* 时 θ(r) > α，r ≥ r* 时 θ(r) ≤ α | 单调性成立时自动满足；若不成立则分区间独立处理 |

> **与旧版（v2.0）的关键变化：** 旧 H1（局部平滑）被 H1（离散分箱充分性）取代——不再假设 θ(r) 局部线性。旧 H4（单调性未强制）升级为 H4（强制+可回退）。旧 H6（高斯核边界）因核回归完全移除而删除。

## 二、当前方法（P51 实施后）

### 三阶段管线

```
资源数据 (r_i, y_i)
       │
       ▼
① binsglm 分位数分箱（CCFF 2024a/b）
   │  dist='Binomial', ci=False, cb=False（只取 dots，不触发 SVD 路径）
   │  IMSE 准则自动选择箱数 J
   │  输出：x_left, x_right, x_center, p̂_j = K_j/N_j, N_j
   │
       ▼
② PAVA 保序估计（Barlow et al. 1972; Robertson et al. 1988）
   │  单调递减约束下 O(J) 合并逆向波动
   │  合并操作：K_pool / N_pool = 约束 MLE
   │  输出：θ̃_l (l=1…L ≤ J)、blocks、theta_per_bin
   │
   ├── 单调性诊断 ──── Wilson SE × 3σ 阈值检测策略断点
   │   若断点存在 → 全局回退独立检验 + Sidak 校正
   │
       ▼
③ Bootstrap 变更点推断
   │  ĵ* = max{j: θ̃_j > α}
   │  固定箱边界上非参数 Bootstrap（仅重新计数 + PAVA，不重跑 binsglm）
   │  95% 变更点 CI → [ĵ*_lo, ĵ*_hi] → [x_star_lo, x_star_hi]
   │  脆弱区间：左界 = 0，右界 = x_star_hi（保守端）
   │
       ▼
   输出：脆弱区间 + 变更点 CI + 单调性诊断报告
```

### 回退路径

binsglm 失败 → `_logistic_ll_fit`（局部逻辑回归）+ 曲线走查法（旧方法，保留为最后手段）。回退时 GUI 状态栏显示警告。

### 与旧方法（v2.0 核回归）的本质区别

| | v2.0 核回归 | v3.0 离散分箱 + PAVA |
|---|---|---|
| 平滑假设 | θ(r) 局部近似线性（logit 变换后） | 无——箱内 θ(r) 视为常数 |
| 推断单位 | 200 个格点（连续） | J 个分箱（离散，~15-30） |
| 带宽选择 | Silverman 规则（核密度用，非回归用） | IMSE 自动选 J（数据驱动） |
| 多重性 | 200 次独立检验，无校正 | 1 次变更点估计 |
| 单调性 | 不强制（估计结果可能违反经济直觉） | 强制递减（PAVA），可诊断可回退 |
| 稀疏区处理 | 全局等带宽 → 方差大 | 分位数分箱 → 自动扩箱 |
| 噪声尖峰 | 需 persistence 过滤 | PAVA 自动与邻箱合并 |
| 置信区间 | 无 | Bootstrap 变更点 CI（95%） |

## 三、已知局限性

### A 层：方法缺陷（P15 + P51 已全面修复）

| # | 缺陷 | 严重度 | 旧方案 | P51 修复 | 状态 |
|---|------|--------|--------|---------|------|
| A | r_grid 边界硬限制 | 🔴 严重 | `[r_min, r_max]` | r_grid 扩展 10% 边距 | ✅ P15 阶段一 |
| B | LLR 左边界偏差 | 🔴 严重 | 核右侧有数据左侧无 | 左边界向左扩展一个带宽 | ✅ P15 阶段一 |
| C | 线性回归用于二元响应 | 🟡 中等 | LLR → 裁剪到 [0,1] | `_logistic_ll_fit` IRLS 实现 | ✅ P15 阶段一 |
| D | Silverman 带宽非回归最优 | 🟡 中等 | 核密度估计规则 | binsglm IMSE 选 J——无带宽概念 | ✅ P51 |
| E | 200 格点无多重性校正 | 🟡 中等 | 逐点阈值 | 变更点 CI——J 次检验 → 1 次 | ✅ P51 |
| F | 无 persistence 过滤 | 🟡 中等 | 1-2 格点噪声判为脆弱 | PAVA 自动合并逆向箱 | ✅ P51 |
| G | 全局等带宽不适应密度 | 🟢 低等 | 稀疏区方差大 | 分位数分箱——每箱等样本量 | ✅ P51 |
| H | FD 分箱偏斜分布分辨率不足 | 🟢 低等 | FD 规则 | `compute_bins()` 统一入口；等距直方图仅展示用 | 🔵 改善 |
| I | 因果性声明隐式假设 | 🟢 低等 | 无说明 | 关于页面 + 本文档明确标注关联非因果 | ✅ P51 T4 |

### B 层：框架固有局限（任何方法均无法在当前框架内消除）

这些不是「方法选错了」，而是「分析框架本身」的约束。即使换方法（核回归、神经网络、贝叶斯），只要输入是「(资源, 成败) 点集 → 条件概率曲线 → 脆弱区间」，这些问题就存在。

| # | 局限 | 根源 | 影响 | 可能的根本解决方向 |
|----|------|------|------|------------------|
| L1 | **GDR 阈值二元化信息损失**（旧 H2） | 连续 GDR 值被截断为 0/1，丢失「接近成功」vs「差得很远」的区分 | 中间阈值（如 α=0.5）时大量「部分成功」样本被粗暴分类；阈值取极端值时损失更严重 | 序数 logistic 回归（3+ 有序类别）或直接建模 GDR 连续值分布 |
| L2 | **条件独立性违反——多池策略依赖**（旧 H3） | 同一模拟的各池结局共享底层运气因子（如早期池歪了 → 后续资源少 → 连锁失败），不是独立观测 | 方差估计偏小，置信带偏窄——对脆弱区间的确定性过度自信 | 多层模型（模拟级随机截距）；cluster-robust 标准误；GEE |
| L3 | **幸存者偏差**（旧 H4 的部分） | 极低资源区间的样本是选择性的——能活到低资源还没失败的模拟，其底层运气可能系统性偏优 | 左尾部 θ(r) 可能被低估——极低资源区间的失败概率看起来低于真实值 | 因果推断框架（do-calculus / 工具变量）；逆概率加权（IPW） |
| L4 | **资源作为固定设计点的 Berkson 误差**（旧 H5） | 将随机资源值当作固定协变量，忽略其抽样变异 → 相当于在 x 轴上有测量误差 | 回归曲线向均值收缩（attenuation bias）；脆弱区间边界估计偏保守 | Errors-in-variables 模型；SIMEX；贝叶斯测量误差模型 |
| L5 | **Bootstrap CI 的渐近有效性** | 变更点 Bootstrap CI 在大样本下名义覆盖率为 95%，有限样本（n < 1000）下实际覆盖率未知 | 小样本下 CI 可能偏窄或偏宽——名义 95% 可能实际只有 80% 或高达 99% | 模拟校准研究（Monte Carlo 评估实际覆盖率）；双 Bootstrap（计算成本高） |
| L6 | **r=0 边界无法估计** | 若数据中不存在资源接近 0 的模拟（大部分模拟在资源耗尽前就停止了），θ(r→0) 不可估计 | 脆弱区间左界固定为 0（保守），但无法验证该区域的真实失败概率 | 外推需额外假设（如参数形式），但会引入新的模型风险 |
| L7 | **binsglm IMSE 选 J 是工程启发式** | IMSE 准则最小化积分均方误差，但无有限样本最优性理论保证 | J 的选取可能不是「最优」的（但通常「足够好」） | 交叉验证选 J；或多分辨率分箱 + 汇总（计算成本高） |

> **关键区分：** A 层缺陷是「方法在数学上站不住脚」——P51 修的就是这些。B 层局限是「问题本身的难度」——框架不变就无法消除，只能明确标注，让用户知情决策。

## 四、假设违反的后果速查

| 假设 | 违反情景 | 在新框架下的后果 |
|------|---------|----------------|
| H1: 离散分箱充分性 | 箱内 θ(r) 变化剧烈（如 J 太小导致箱太宽） | 箱内平均掩盖了真实结构——变更点偏移最多 1 箱宽；可增大 J 缓解 |
| H4: 单调递减 | 策略切换处 θ(r) 局部跃升（如 target_hunting 跨池时资源阈值效应） | 诊断检测为 breakpoint → 全局回退独立检验 + Sidak；UI 标注「单调性不适用」 |
| H6: 变更点存在性 | 脆弱/安全区间交替出现（如 M 形） | 变更点 ĵ* 仅捕获最后一个脆弱箱——遗漏后续的脆弱区域；需分区间独立分析 |
| — (旧 H2) | GDR 阈值取中间值 | 见 B 层 L1——二元化丢失信息，任何方法均受影响 |
| — (旧 H3) | 多池策略依赖 | 见 B 层 L2——方差低估，置信带偏窄 |
| — (旧 H4 幸存者偏差) | 极低资源区样本稀少+选择性强 | 见 B 层 L3——左尾部估计失真 |

> 旧 H1（局部平滑）和旧 H6（高斯核边界）已因核回归移除而不再适用。
