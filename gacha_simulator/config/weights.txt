# Card Weight Configuration
# Format: card_id | desire_weight | miss_cost_weight | card_value
#
# desire_weight:   抽取意愿权重——成功抽出该卡时获得的满意度权重，用于加权满意度计算
# miss_cost_weight: 错失代价权重——未能抽出该卡时的遗憾代价权重，用于后续分析方法（如后退法排序）
# card_value:       单卡价值——每张卡的价值系数，用于总出卡价值等广义出率计算
#
# 所有权重默认 1.0。可根据实际需求调整：越想要的卡 desire_weight 越高；
# 越不能错过的卡 miss_cost_weight 越高；越珍贵的卡 card_value 越高。
