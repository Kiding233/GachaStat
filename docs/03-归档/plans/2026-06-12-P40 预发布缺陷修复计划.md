## 可观测性策略

本计划在 5 个模块（pity / strategy / batch_simulator / config_io / resource_gain）中新增日志——必须有统一的日志策略以确保这些改进实际生效。

**决策：**

1. **CLI 入口日志配置** — `cli.py` 的 `main()` 入口处调用 `logging.basicConfig(level=logging.WARNING, format='%(levelname)s:%(name)s:%(message)s')`，确保所有 `logger.warning()` 在 CLI 模式下可见。此修改在任务 6 执行时一并完成（同一文件 `cli.py`）。

2. **日志级别统一** — 所有新增的异常诊断日志使用 `logger.warning()` 级别（非 `logger.debug()`），确保在 Python 默认 WARNING 级别下可见。具体：(a) 任务 9 的 5 处 `logger.debug()` 统一改为 `logger.warning()`；(b) 任务 2/5/11/24/28 的新增日志已使用 `logger.warning()`。

3. **GUI 日志可见性** — GUI 模式下日志由 PyQt6 应用事件循环处理。若 `logging.basicConfig` 未在 GUI 入口调用，日志输出到 stderr——启动 GUI 时可在终端中观察。GUI 日志增强由任务 24（config_io）覆盖。

4. **验证** — 在阶段间集成验证和 CLI 冒烟测试中增加日志输出确认步骤（见验证方案修改）。

class _BootstrapWorker(QThread):
    """后台 Bootstrap 计算线程——防 UI 冻结"""
    finished = pyqtSignal(list)  # 发射 [(gdr_key, result_dict), ...]
    progress = pyqtSignal(int)   # 百分比
    error = pyqtSignal(str)

    <!-- REVIEW-R1-FIX: ISSUE-031 增加 use_draw_units/cost_per_draw 参数——防止「以抽数为单位」显示模式在异步迁移后静默失效 -->
    def __init__(self, results, target_specs, ssr_ids,
                 alpha, ci_level, resource_defs, store,
                 use_draw_units=False, cost_per_draw=0,
                 parent=None):
        super().__init__(parent)
        self._results = results          # List[CompactResult]——所有模拟结果
        self._target_specs = target_specs
        self._ssr_ids = ssr_ids
        self._alpha = alpha
        self._ci_level = ci_level
        self._resource_defs = resource_defs  # dict——传给 get_expanded_gdr_entries()
        self._store = store
        self._use_draw_units = use_draw_units  # ISSUE-031: 是否以抽数为单位
        self._cost_per_draw = cost_per_draw    # ISSUE-031: 每抽成本

    def run(self):
        try:
            <!-- REVIEW-R1-FIX: ISSUE-027 is_probability_gdr 在 gdr.py/全代码库中不存在——已移除该导入 -->
            from gacha_simulator.core.gdr import (
                get_expanded_gdr_entries, make_gdr_calculator,
                is_resource_gdr,
            )
            from gacha_simulator.core.bootstrap import BootstrapEngine
            from gacha_simulator.core.distribution import EmpiricalDistribution
            import numpy as np

            # ⚠️ ISSUE-020(c): 引擎在循环外创建单例——保证随机种子可复现
            engine = BootstrapEngine(
                B=1000, ci_level=self._ci_level, random_seed=42,
            )

            # ⚠️ ISSUE-020(b): get_expanded_gdr_entries 接收 resource_defs dict
            # （不是 GDRContext 对象）
            entries = get_expanded_gdr_entries(self._resource_defs)
            total = len(entries)
            results = []

            for i, (key, d_name, lower_is_better, _threshold) in enumerate(entries):
                if self.isInterruptionRequested():
                    break

                # 构造 GDR 计算器（含权重——遵循 CLAUDE.md 强制规范）
                checker = make_gdr_calculator(
                    self._store, self._target_specs, key,
                    ssr_ids=self._ssr_ids,
                )
                # 对所有模拟结果预计算值列表
                vals = [checker.compute_gdr(r) for r in self._results]
                <!-- REVIEW-R1-FIX: ISSUE-031 资源型 GDR 的 draw unit 变换——与现有同步代码（analysis_panel.py:2159-2160）保持一致 -->
                if is_resource_gdr(key) and self._use_draw_units and self._cost_per_draw > 0:
                    vals = [v / self._cost_per_draw for v in vals]
                n = len(vals)
                mean_val = np.mean(vals)
                median_val = np.median(vals)
                std_val = np.std(vals)
                var_val = EmpiricalDistribution(vals).var(self._alpha)

                result_dict = {
                    'n': n, 'mean': mean_val, 'median': median_val,
                    'std': std_val, 'var': var_val,
                }

                <!-- REVIEW-R1-FIX: ISSUE-027 移除 is_probability_gdr() 分支与 _get_threshold() 调用——两个函数均不存在于代码库 -->
                <!-- 统一使用 bootstrap_mean + bootstrap_quantile 处理所有 GDR 类型——与现有同步代码（analysis_panel.py:2155-2224）行为一致 -->
                if n >= 100:
                    # ⚠️ ISSUE-020(a): 分派到实际方法——无通用 compute()
                    # 统一对所有 GDR 类型使用 bootstrap_mean + bootstrap_quantile
                    mean_res = engine.bootstrap_mean(vals, use_bca=True)
                    result_dict['mean_ci'] = (
                        f"[{mean_res.ci_lower:.4f}, {mean_res.ci_upper:.4f}]"
                    )
                    median_res = engine.bootstrap_quantile(vals, q=0.5)
                    result_dict['median_ci'] = (
                        f"[{median_res.ci_lower:.4f}, {median_res.ci_upper:.4f}]"
                    )
                    var_res = engine.bootstrap_quantile(vals, q=self._alpha)
                    result_dict['var_ci'] = (
                        f"[{var_res.ci_lower:.4f}, {var_res.ci_upper:.4f}]"
                    )
                else:
                    result_dict['mean_ci'] = '样本不足'
                    result_dict['median_ci'] = '样本不足'
                    result_dict['var_ci'] = '样本不足'

                results.append((key, d_name, lower_is_better, result_dict))
                self.progress.emit(int((i + 1) / total * 100))

            self.finished.emit(results)
        except Exception as e:
            import traceback
            traceback.print_exc()
            self.error.emit(str(e))
