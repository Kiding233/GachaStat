## 一、核心假设

### 1.1 概率调整的可加性假设

多保底管道假设**保底效果可叠加**——保底 A 调整概率分布后，保底 B 在 A 的结果上继续调整。P55 通过 `_resolve_order(behaviors, rarity_rank)` 控制执行顺序：先按稀有度层级（高稀有度优先），再按 type 优先级（counter_soft→counter_hard→event_driven_soft→event_driven_hard）。

**隐含假设**：
1. **调整方向一致性**：所有保底增加同一方向（提高高稀有度概率）。
2. **单调性保持**：概率调整后所有值的和为 1.0（归一化不变）。
3. **顺序依赖**：管道的最终概率分布依赖于保底的应用顺序——由排序算法确定性保证。

### 1.2 目标定向机制

P55 通过 `target_featured` + `scope` + `featured_slots` 槽位分离实现定向提升。`compute_scope_mappings(pool)` 将 featured SSR 拆分为独立槽位 `ssr_featured`，概率提升仅作用于该槽位——standard SSR 保持基础概率不变。等价于旧系统的 `target_distribution` + `resolved_targets`，但通过声明式槽位系统替代运行时解析。

### 1.3 软保底概率递增模型（P55：RLE deltas）

P55 用 RLE（游程编码）deltas 统一替代旧三种 `func_type`：

```
deltas = ((起始段抽数, 每抽增量%), ...)
例：((80, 0.0), (10, 10.0)) → 前80抽0%→后10抽每抽+10%→第90抽到达100%
```

`soft_interval` / `soft_additive` 在 TOML 解析时通过 `_expand_soft_to_deltas()` 展开为 deltas，统一由 `SoftStepBehavior` 消费。仅 `linear` 被保留——`exp` / `step` 函数已移除。

### 1.4 重置条件

| 条件 | 含义 | 行为 |
|------|------|------|
| `featured` | 仅 featured SSR 重置计数器 | 提升仅对 featured 槽位，标准 SSR 保持基线概率 |
| `ssr` | 任何 SSR 出卡后重置 | 标准 gacha 行为 |
| （默认） | 未设置时回退为 scope 值 | 与 scope 同名的稀有度出卡时重置 |

`_should_reset()` 中 `self._reset` 参数与 `self._target_featured` 正交——支持「仅提升 featured 但任意 SSR 重置」等灵活组合。

## 二、多保底管道优先级（P55 实现）

### 2.1 执行顺序

`_resolve_order(behaviors, rarity_rank)` 确定管道执行顺序：
1. **稀有度层级优先**：高稀有度（rank 值小）先执行，防止低稀有度保底抢占高稀有度概率
2. **type 分类次之**：counter_soft(0) → counter_hard(1) → event_driven_soft(2) → event_driven_hard(3)
3. **name 字母序兜底**：同优先级按 name 确定性排序

`_validate_behaviors()` 提供配置层安全网：同 scope 两个 hard → `ConfigError`、同 scope 两个事件驱动型 → `ConfigError`、同 scope 同 type 两个 soft → `ConfigError`。

### 2.2 管道语义

保底按排序后的 `_behavior_list` 顺序依次调整概率。后应用的保底覆盖前者的调整是管道模式的预期行为——允许配置者通过保底 type 和 scope 控制优先级。

## 三、P55 概率调整的数学分析

### SoftStepBehavior._cumulative_boost() + _compute_probabilities()

给定 counter 值和 RLE deltas `((n₁, inc₁), (n₂, inc₂), ...)`：
scale = new_other_prob / other_prob

p'_i = {
    new_target_prob × (w_i / Σw_j)    if i ∈ target
    p_i × scale                       if i ∉ target
}
```

**数学性质**：
- 归一化保持：`Σ p'_i = 1`（当 `new_target_prob < 1` 时）
- 相对权重保持：目标卡之间的相对比例不变，非目标卡之间的相对比例不变
- `progress = 0 →` 不调整；`progress = 1 →` 目标卡概率达到 1.0

### HardPityBehavior.apply()

当 `counter >= threshold`：目标卡概率 = 按 `resolved_targets` 权重分配 1.0，其他卡概率 = 0.0。
