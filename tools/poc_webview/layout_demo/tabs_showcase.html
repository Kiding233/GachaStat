C 段 · 基于 8（card 式）的六个变体

8 的 tag 间间隔显大，原因是 gap:3px 加上每个 tag 各自的左右边框，等于两条边框中间夹一条空缝。 C 段统一先把间距收紧（相邻 tag 共边，用负外边距吃掉重复的那一条），再逐项试「文字左边加点东西」。 标记全部用同一档灰，不占用语义色。

C1 · 只收紧间距

不动 8 的任何造型，只把 tag 相邻共边、内边距从 11px 收到 10px。先看间距这一项本身能补回多少。

D 段 · 右侧可折叠时间线预览栏

这就是「去掉文本栏之后，右栏放什么」的答案。它对应现行 WebUI 的 `ConfigPreview`： 上为累积资源曲线（各资源着色），中为池子开放区间（甘特），下为保底 / 累抽规则的作用池（台阶中点 + 竖直虚线）。 与文本栏的关键差别是：它是**全配置的视图**，不是文本的副本；而且改左边表单时右边立刻跟着变，所以「边改边看」这个价值保住了。
