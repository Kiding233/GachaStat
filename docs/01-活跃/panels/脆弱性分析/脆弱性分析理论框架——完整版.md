## 一、问题识别

> 来源：P15 §二

脆弱性分析要回答两个问题：

1. **P(失败 | 资源剩余=r)** —— 给定池结束时资源水平，最终失败的概率是多少？
2. **脆弱区间检测** —— 存在哪些资源水平区间，使得失败概率超过用户容忍阈值 α？

统计本质：问题 1 是**条件期望估计**（E[Y|X=r], Y∈{0,1}），问题 2 是**阈值区域检测**（{r : E[Y|X=r] > α}）。

### 1.1 严重问题

**问题 A：r_grid 边界硬限制，无法检测数据范围外的脆弱区域。** LLR 曲线仅在 `[r_min, r_max]` 上估计，脆弱区间的左边界不可能低于 `r_min`。极端情况下（所有到达该池的模拟资源剩余都 > 500），即使资源接近 0 时失败必然，也报告「无脆弱区间」。

> **重评估（2026-06-14）降级为低等。** 脆弱区间下界对退路搜索无影响——策略只依赖右界。外推到 r=0 创造无数据支撑的虚假信息。正确做法：不做数学外推，UI 标注限制。

**问题 B：局部线性回归在左边界处的系统性偏差。** 核函数在低资源区右侧有数据左侧没有，估计值向数据内部收缩。P(失败|r) 在低资源区域被系统性低估。

### 1.2 中等问题

**问题 C：二元响应变量使用线性回归而非逻辑回归。** （阶段一已修复——`_logistic_ll_fit` Newton-Raphson 迭代，不收敛时回退 LLR。）

**问题 D：带宽选择使用了密度估计而非回归的最优公式。** Silverman 规则 `h = 1.06·σ·n^(-0.2)` 为核密度估计推导——假设回归函数曲率为常数。当 P(失败|r) 存在急剧转折，带宽偏宽，转折被过度平滑。Fan & Gijbels (1995) 提出了针对回归的残差平方准则（RSC）带宽选择。

**问题 E：脆弱区间检测缺乏多重性校正。** 在 200 个格点上同时做 `lp_curve > alpha` 的阈值判断——即使零假设为真也可能产生伪区间。Härdle & Mammen (1991) 的 Wild Bootstrap 可构造同时置信带。

**问题 F：无最小区间宽度（persistence）过滤。** 1~2 格点宽的噪声尖峰也会被当作脆弱区间。

### 1.3 低等问题

**问题 G：全局等带宽不适应局部数据密度变化。** 低资源区数据稀疏，等带宽在稀疏区方差过大。Fan & Gijbels (1995) 的变带宽方法或 LOESS 风格最近邻带宽可缓解。

**问题 H：直方图分箱规则的边界效应。** Freedman-Diaconis 规则使用 IQR，对偏斜数据分辨率不足。

**问题 I：因果性声明的隐式假设。** 估计的是关联关系，应在 UI 中标注。

### 1.4 核心判断

9 项缺陷中有 7 项（B/D/E/F/G/H）源自**「通过拟合光滑曲线来做推断」这一方法论选择本身**。问题可以更根本地解决——不使用光滑曲线。

## 二、文献调查：分箱方案替代回归的可行性

> 来源：文献调查报告。方法：WebSearch + 文献交叉验证 + 学术标准。

### 2.1 CCFF 2024：现代 Binscatter 理论

**Cattaneo, Crump, Farrell & Feng (2024a)** "On Binscatter." *American Economic Review*, 114(5), 1488–1514.（经济学 Top 3 期刊）
**Cattaneo, Crump, Farrell & Feng (2024b)** "Nonlinear Binscatter Methods." arXiv:2407.15276 [stat.EM].（预印本，未经同行评审）

首次为 binscatter 提供完整统计推断框架——此前 binscatter 仅作为非正式可视化工具。

关键结果：

1. **IMSE 最优箱数**（2024b, §3.2）：
   ```
   J_IMSE = ⌈(B_n(p,s,v) / V_n(p,s,v))^(1/(2p+3)) · n^(1/(2p+3))⌉
   ```
   对分段常数 (p=0, s=0, v=0)：J ∝ n^(1/3)。

2. **统一置信带**（2024b, §4）：基于高斯过程强逼近和模拟临界值，保证同时覆盖概率 → 1−α。临界值 c 通过模拟 `sup_x |Ẑ_p(x)|` 分布获得，不依赖独立性假设。

3. **Logistic 分箱回归**（`binslogit`）：对二值响应使用局部似然框架的分段常数/多项式 GLM 估计，自动处理异方差，提供有效逐点 CI 和统一置信带。

4. **Python 包 `binsreg`**：PyPI 可安装（依赖 numpy/pandas/scipy/statsmodels）。

**反证检索**：未找到对 CCFF 2024 方法的已发表批评或反证。方法基于成熟强逼近理论（Rio 1994; Chernozhukov et al. 2014），理论根基稳固。

### 2.2 Signorini & Jones (2004, JASA) —— 权威系统比较

**Signorini, D.F. & Jones, M.C.** (2004). Kernel Estimators for Univariate Binary Regression. *JASA*, 99(465), 119–126.

- 局部线性逻辑回归是「最佳单带宽估计量」
- **基本 Nadaraya-Watson（分箱的平滑泛化）「也表现相当好」**
- 双带宽方法在实际数据驱动带宽选择下优势丧失
- 推荐混合策略：默认局部逻辑回归；当成功/失败组的协变量方差比 > 2 时切换到双带宽 NW

> 对本项目的含义：Signorini & Jones 的比较是**曲线估计精度**（MISE），不是阈值检测功效。分箱在 MISE 上不如平滑回归——但在阈值检测问题上，这一点的重要性有待论证。

### 2.3 Okumura (2011) —— 渐近方差等价定理

**Okumura, H.** (2011). A Local Linear Type Estimator with a Weighted Kernel in Nonparametric Binary Regression. *Journal of the Japan Statistical Society*, 41(1), 1–18.

NWE（分箱的连续泛化）、局部线性（OLLE）、局部逻辑（LLLE）三者具有**相同的渐近条件方差**：
```
AV = [μ₀(K²) / (n·h)] · [p(x)(1-p(x)) / f(x)]
```
差异仅在渐近偏差项——局部线性和局部逻辑消除了 NWE 中的**设计密度偏差**项 `2p'(x)f'(x)/f(x)`。

> 对本项目的含义：若资源分布严重偏斜（f'(x) 大），分箱/NWE 的偏差会增大。但**分位数分箱**（等样本量箱）自动使 f(x) 在箱内近似均匀，从而消除此偏差。

### 2.4 精确二项推断（Wilson 1927）

**Wilson, E.B.** (1927). Probable inference, the law of succession, and statistical inference. *JASA*, 22(158), 209–212.

Wilson 得分区间：
```
p' = (p̂ + z²/(2n)) / (1 + z²/n)
CI = p' ± z√(p̂(1-p̂)/n + z²/(4n²)) / (1 + z²/n)
```

与 Wald CI 的关键区别：Wald CI 在 p̂=0 或 p̂=1 时宽度塌缩为 0——覆盖率严重不足；Wilson CI 始终保持非零宽度。UK Public Health England 官方指南强制要求对二项比例使用 Wilson 方法。

### 2.5 分段常数回归用于变点检测

**Pein, F.** (2021). Change-point regression with a smooth additive disturbance. arXiv:2112.03878.（预印本）

对于变点（阈值跨越点）的定位，分段常数模型可达到**参数速率 1/√n**。使用核平滑而不利用分段常数结构时，变点估计速率严格慢于 1/√n（需要 undersmoothing）。

> 对本项目的含义：脆弱区间检测本质是找 P(失败|r) 曲线与 α 水平线的**交点**（变点检测）。分段常数模型在变点定位上的理论效率**不低于**平滑模型。

### 2.6 单调性约束

**Lee, Y.-S.** (2007). A Comparison of Methods for Nonparametric Estimation of Item Characteristic Curves for Binary Items. *Applied Psychological Measurement*, 31(3), 223–238. — 平滑等渗回归显著优于无约束核平滑。

**Mallick, A., Sarkar, P. & Kuchibhotla, A.K.** (2023). New Asymptotic Limit Theory and Inference for Monotone Regression. arXiv:2310.20058.（预印本）— **Bootstrap 在等渗回归推断中不一致**——Bootstrap 无法正确复现等渗估计量的非标准渐近分布。

> 对本项目的含义：P(失败|r) 应当单调非增。分箱方案可以天然强制单调性（合并违反单调性的相邻箱），而平滑回归需要额外约束优化。Mallick et al. 的发现进一步反对用 Bootstrap 做等渗推断——变更点置信区间走混合卡方是更安全的选择。

### 2.7 反证检索结果

检索以下主张的反证，未发现已发表文献：

- 「Wilson CI 覆盖率低于名义水平」→ **无**（Wallis 2013 的 11 方法评估确认 Wilson 为最优）
- 「分箱应在所有情况下被平滑回归替代」→ **无**（CCFF 2024a 明确论证分箱在特定场景下优于平滑）
- 「binscatter 不适合统计推断」→ **无**（CCFF 2024 正是为了填补这一空白而发表）

### 2.8 binsreg API 验证结论（2026-06-14）

| 验证项 | 结果 | 说明 |
|--------|:--:|------|
| 安装 | ✅ | `binsreg` 3.1.0, PyPI |
| API 函数名 | ⚠️ | `binsglm(y, x, dist='Binomial')` 非 `binslogit` |
| `dots.fit`（箱级比例） | ✅ | 分位数分箱 + 分段常数估计 |
| `ci.ci_l`/`ci_r`（逐点 CI） | ✅ | 正常，但走 Wald 近似 |

**结论：只取 binsglm 的分箱（dots），丢弃其所有推断层（ci/cb/polyci）。推断全部自己来。**

### 2.9 最终方案选择

| | binsreg 纯方案 | 离散分箱 + 保序（本方案） |
|---|---|---|
| 分箱 | binsglm IMSE 最优 | 同左 |
| 估计 | dots + 可选 line/poly | PAVA 保序估计 |
| 推断 | 高斯过程极值模拟（cb） | 变更点置信区间 |
| 数值风险 | SVD 近奇异（已验证崩溃） | 无（PAVA 无矩阵分解） |
| 离散数据兼容 | 理论依赖连续光滑假设 | 仅需单调性（可检验） |
| 多重性处理 | 极值分布自动覆盖 | 单调性降维（J→1） |

## 三、离散分箱框架：两个命题

> 来源：离散分布与分箱的脆弱性分析——两个理论问题

### 3.1 数据与记号

n 次独立模拟，第 i 次产出 `(R_i, Y_i)`：
- `R_i ∈ R = {0, c, 2c, …, r_max}`，c = cost_per_draw（典型 160）
- `Y_i ∈ {0, 1}`，1 = 未达成 GDR 目标（失败）
- `θ(r) = P(Y = 1 | R = r)`

分箱：将 R 划分为 J 个不相交连续区间 B₁, …, B_J（按资源递增排列）。箱 j 内：
- `N_j = #{i : R_i ∈ B_j}`，`K_j = #{i : R_i ∈ B_j, Y_i = 1}`
- `θ_j = P(Y = 1 | R ∈ B_j) = E[θ(R) | R ∈ B_j]`
- `θ̂_j = K_j / N_j`

### 3.2 结构假设：单调递减

资源越多 → 可抽次数越多 → 成功概率越高 → 失败概率越低：

```
若策略行为在 [r₁, r₂] 内不变，则 r₁ < r₂ ⇒ θ(r₁) ≥ θ(r₂)
```

**为什么几乎总是成立。** 每次抽卡独立以非负概率贡献于目标。额外抽卡至少不会降低成功机会。

**为什么不是必然。** 策略可能包含资源阈值——target_hunting 在资源 > X 时转向更难池，pity_reserve 在阈值处改变行为。这些阈值处可能产生 θ(r) 的局部上升。

**处理方式：** 默认假设单调递减，同时：
1. **诊断**——检查原始比例 p̂_j 的逆向波动幅度是否超过采样噪声可解释范围
2. **回退**——若确认为策略断点，局部关闭 PAVA → 回退独立检验 + Sidak
3. **PAVA 稳健性**——只在逆向波动处合并，满足约束处不做改动。损害局限在断点附近

### 3.3 命题一：P(失败 | 资源剩余 = r) 的估计

**朴素逐点估计不可行。** n 次模拟分布在 m ≈ 300 个格点上，平均每格点仅 1–7 次观测。n_r = 0 时无定义，n_r = 1 时 p̂ ∈ {0, 1}——无法区分信号与噪声。若不对 θ(r) 做任何结构假设，有 m ≈ 300 个自由参数需要估计——n 次观测不足以支撑。

**分箱将问题转化为 θ_j = E[θ(R) | R ∈ B_j]。** 估计量 θ̂_j = K_j/N_j。不存在光滑假设时，聚合偏差 b_j(r) = θ_j − θ(r) 的上界仅由箱内 θ(r) 的极差控制。箱越窄偏差越小，但 N_j 越小方差越大——经典偏差-方差权衡在离散数据上的形式。

**PAVA 保序估计改进。** 无约束 θ̂_j 可能因采样噪声违反单调方向。PAVA（Pool Adjacent Violators Algorithm）在单调约束下求 MLE。性质：
- 只在逆向波动处合并（若原始已递减则不做改动）
- 合并 = 约束 MLE——K_pool/N_pool
- 权重 = N_j（二项 Fisher 信息正比于 N_j）
- MSE(θ̃) ≤ MSE(θ̂) 当单调性成立时
- O(J) 时间，无迭代参数

### 3.4 命题二：脆弱区间的检测

**单调性强制脆弱区间为前缀形式**——脆弱箱集中在低资源端：

```
[脆弱] [脆弱] … [脆弱] | [安全] [安全] … [安全]
```

不可能出现「中间脆弱、两端安全」的模式。因此不是 J 个独立检验，而是**单一变更点估计**：

```
ĵ* = max{ j : θ̃_j > α }
```

脆弱区间 = `[min(B₁), max(B_ĵ*)]`。

**ĵ* 的置信区间**通过倒转似然比检验构造——在单调约束下比较「强制变更点在 j₀」与「数据自由选变更点」的似然。统计量 Λ(j₀) 在 H₀ 下服从混合卡方分布（chi-bar-squared）：

```
P(Λ > c) = Σ_{k=1}^{L} w_k(L, V) · P(χ²_k > c)
```

其中 L 是 PAVA 收敛后的块数，V 是约束矩阵，w_k 是混合权重（可模拟或查表）。Bootstrap 备选方案可用但需注意 Mallick et al. (2023) 的警告——Bootstrap 在等渗回归中不一致，变更点 CI 的 Bootstrap 校准需在固定箱边界上进行（不重跑 binsglm）。

**对用户的呈现**——脆弱区间右界有三种表述：

```
保守估计: B_{ĵ*_hi}（取 CI 上界——准备更多资源）
点估计:   B_{ĵ*}（最大似然）
乐观估计: B_{ĵ*_lo}（取 CI 下界）
```

退路搜索采用保守端作为安全资源下限。

### 3.5 与独立检验 + Sidak 的比较

| | J 个独立检验 + Sidak | 保序 + 变更点 |
|---|---|---|
| 决策维度 | J | 1 |
| FWER 校正成本 | O(J) | O(1) |
| 采样逆向波动 | 可能产生断裂脆弱区间 | PAVA 自动吸收 |
| 结构假设 | 无（仅分区独立性） | 单调递减（可检验、可回退） |
| 假设违反时 | 不受影响 | PAVA 仅在违反处偏差 → 诊断回退 |

## 四、PAVA 算法

> 来源：PAVA 算法详解 + 有序约束下的二项推断 §二

### 4.1 直觉

从左往右扫。遇到反方向的两个相邻箱，就混在一起当一个大箱。混完后回头看一眼——会不会又和更左边的反了？反了就继续混。混到所有相邻关系都顺了为止。

### 4.2 算法

```
输入: p̂[1..J],  w[1..J]    ← 原始比例和权重（w_j = N_j）
输出: θ̃[1..L]               ← L ≤ J 个保序块，θ̃₁ ≥ θ̃₂ ≥ … ≥ θ̃_L

j ← 2
while j ≤ J:
    if θ̃[j-1] ≥ θ̃[j]:        ← 没违反，继续
        j += 1
    else:                     ← 违反！合并
        K_pool = θ̃[j-1]·w[j-1] + θ̃[j]·w[j]
        w_pool = w[j-1] + w[j]
        θ̃[j-1] = K_pool / w_pool
        删除 θ̃[j], w[j];  J -= 1
        j -= 1                ← 回溯一步，检查是否引出新违反
        if j < 2: j ← 2
```

复杂度 O(J)，确定性单次扫描。

### 4.3 手动追踪

```
初始: p̂ = [0.80, 0.65, 0.72, 0.45, 0.30],  w = [20, 20, 20, 20, 20]

j=2: 0.80 ≥ 0.65 ✓ → j=3
j=3: 0.65 < 0.72 ✗ → 合并箱 2+3:
     K = 0.65×20 + 0.72×20 = 27.4,  w = 40,  p = 0.685
     当前: [0.80, 0.685, 0.45, 0.30]
     回溯 j=2: 0.80 ≥ 0.685 ✓

输出:
  块1: 箱1,　　  θ̃ = 0.80
  块2: 箱2–3,　　θ̃ = 0.685　← 合并消除了采样逆向波动
  块3: 箱4,　　  θ̃ = 0.45
  块4: 箱5,　　  θ̃ = 0.30
```

### 4.4 为什么合并 = 最大似然

两箱真实值受 θ₂ ≥ θ₃ 约束，数据却显示 p̂₂ < p̂₃。在约束下求最优，必然落在边界 θ₂ = θ₃——退化为「用一个 θ 拟合两箱数据」。二项 MLE 的解析解就是加权平均 K_pool/N_pool。

### 4.5 输出：保序估计 + 块结构

PAVA 输出两样东西：

1. **保序估计 θ̃_j**——每箱一个值，满足递减，是约束 MLE
2. **块结构**——J 个箱合并为 L ≤ J 个块，块内共享 θ̃，块间严格递减

块结构的统计意义：
- **方差减小**——合并块有效样本量变大为 N_block，标准误降为原来的 1/√(|块内箱数|)
- **推断简化**——L 个独立块而非 J 个相关箱。混合卡方的自由度取决于 L
- **可视化**——用户看到 L 个水平段，每段一个颜色

### 4.6 PAVA 对脆弱区间检测的影响（数值演示）

```
无 PAVA（独立箱 + Sidak）:
  p̂:   0.82  0.68  0.71  0.55  0.42  0.28
  CI 下界: (各箱独立)
  脆弱? ✓    ✗    ✓?   ✗    ✗    ✗
  → 箱 3 因 p̂=0.71（噪声向上）独判脆弱，箱 2 因 p̂=0.68（噪声向下）丢失
  → 脆弱区间: 断裂为 [B₁] 和 [B₃]，违反单调常识

PAVA + 变更点:
  p̂:   0.82  0.68  0.71  0.55  0.42  0.28
  PAVA: 0.82  0.695 0.695 0.55  0.42  0.28   ← 箱 2+3 合并
  脆弱? ✓    ✓     ✓    ✓?   ✗    ✗
  → 脆弱区间: [B₁, B₃] 或 [B₁, B₄]（取决于变更点 CI）
  → 连续、单调、一致
```

### 4.7 策略断点示例（单调性违反）

```
场景: target_hunting 策略在资源 > 3000 时切换池

原始比例:
  箱:   1      2      3      4      5      6
  p̂:  0.85   0.65   0.45   0.35   0.42   0.30
                                    ↑ 策略断点

诊断: 箱 4→5: p̂₄=0.35 < p̂₅=0.42，逆向 +0.07
      若该位置在多次重复中持续出现 → 标记「疑似策略断点」

处理:
  - 箱 1–4: 单调成立 → PAVA + 变更点 → ĵ* 在箱 2 或 3
  - 箱 4–5 边界: 关闭 PAVA → 独立检验
  - 最终脆弱区间: [B₁, B_ĵ*]（不受断点后数据污染）
```

## 五、与连续核回归框架的对比

| | 连续核回归（旧） | 离散分箱 + 保序（新） |
|---|---|---|
| **θ(r) 的定义** | 连续函数 μ(r) | 离散格点概率 θ(r) |
| **估计方式** | 局部加权似然 → 光滑曲线 | 箱内聚合 → PAVA 保序台阶 |
| **结构假设** | μ ∈ Cˢ（s 阶可微） | θ(r) 单调递减（可检验、可回退） |
| **偏差刻画** | Taylor 展开 → μ″(ξ)·h² | 箱内 θ(r) 极差 |
| **箱数选择** | 带宽 h（IMSE 依赖 μ″² 积分） | binsglm IMSE（工程启发式）+ N_j 约束 |
| **跨箱信息借用** | 核函数（局部加权） | PAVA 合并（仅在对立方向） |
| **置信区间** | 渐近正态（Wald）→ Wild Bootstrap | 混合卡方 / 变更点 Bootstrap CI |
| **多重性处理** | 无（旧）→ 高斯过程极值（CCFF） | 单调性降维 → O(1) |
| **推断渐近依赖** | 全程渐近 | 仅变更点 CI 的临界值需模拟校准 |
| **最稀疏格点行为** | 带宽内借力 → 可能平滑掉真信号 | N_j 小时 ĵ* CI 变宽——不隐藏不确定性 |
| **软件依赖** | 无（NumPy + statsmodels） | binsreg（仅分箱，~92KB 纯 Python） |
