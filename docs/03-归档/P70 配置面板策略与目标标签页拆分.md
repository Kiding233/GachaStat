# P70 配置面板策略与目标标签页拆分

> 日期：2026-07-29 | 状态：已完成
> 触发：为 P69（策略系统重构）和 P41（目标卡实例权重架构改造）提供独立的 UI 基础——当前「策略与目标」混在同一 Tab 中，两个计划的 UI 改动互相拖累
> 前置于：P69 Step 1.7 + P41（远期）

---

## 一、问题

`config_panel.py` 的二级 Tab「策略与目标」将两套独立系统塞进一个标签页：

```
策略与目标（一个 QGroupBox「策略与目标卡」）
├── 策略类型 QComboBox
├── 停止条件 QComboBox
├── 自动等待 QCheckBox
├── 策略参数 QGroupBox
├── 目标卡 QLabel + QTableWidget
├── 添加/移除按钮
├── 提示 QLabel
└── 可用卡ID参考 QListWidget
```

P69 只改策略段（类型下拉、参数渲染），P41 只改目标卡段（实例权重、副本区分）。两者挤在同一 Tab 中导致：(a) 拆分计划时需要额外标注「只改上半/下半」；(b) 未来一方重构时另一方的 widget 引用可能被误触。

---

## 二、目标

将「策略与目标」Tab 拆为两个独立标签页：

| 新 Tab | 内容 | 对应方法 |
|--------|------|---------|
| **抽卡策略** | 策略类型 + 停止条件 + 自动等待 + 策略参数 | `_setup_strategy_tab()`（精简） |
| **目标卡** | 目标卡表 + 添加/移除按钮 + 提示 + 卡ID参考 | `_setup_target_tab()`（新建） |

纯 UI 拆分——不改变任何信号/槽连接、不修改数据流、不调整 widget 属性。对外接口（`get_config()` / `set_config()` / `_on_strategy_type_changed()`）完全不变。

---

## 三、方案

### 单阶段——拆分 `_setup_strategy_tab()` 为两个方法

**文件：** `gui/config_panel.py`

#### Step 1：提取 `_setup_target_tab()`（~45 LOC 新增）

从 `_setup_strategy_tab()` 第 1665-1706 行提取目标卡相关代码：

```python
def _setup_target_tab(self, parent):
    """目标卡编辑标签页。"""
    group = QGroupBox("目标卡")
    layout = QVBoxLayout(group)

    target_label = QLabel("目标卡（卡ID + 需求数量）:")
    layout.addWidget(target_label)

    self.target_table = QTableWidget()
    # ... （与现有代码完全一致，不修改） ...
    layout.addWidget(self.target_table)

    )
    hint_label.setWordWrap(True)

    layout.addWidget(hint_label)

    card_ref_label = QLabel("可用卡ID参考（双击可添加到目标卡）:")
    layout.addWidget(card_ref_label)

    self.card_id_list = QListWidget()
    self.card_id_list.setMinimumHeight(120)
    self.card_id_list.itemDoubleClicked.connect(self._on_card_id_double_clicked)
    layout.addWidget(self.card_id_list)

    parent.addWidget(group)
```

#### Step 2：精简 `_setup_strategy_tab()`（-45 / +5 LOC）

删除目标卡相关行（1665-1711），仅保留策略段，QGroupBox 标题从「策略与目标卡」改为「抽卡策略」：


#### Step 3：更新 `_setup_ui()` Tab 注册（~6 LOC 新增）

将 1 个 Tab 替换为 2 个：

```python
# 旧（~12 行）
strategy_tab_scroll = QScrollArea()
...
self.left_tabs.addTab(strategy_tab_scroll, "策略与目标")

# 新（~18 行，替换上述）
strategy_tab_scroll = QScrollArea()
...
self._setup_strategy_tab(strategy_tab_layout)
self.left_tabs.addTab(strategy_tab_scroll, "抽卡策略")

target_tab_scroll = QScrollArea()
target_tab_scroll.verticalScrollBar().setSingleStep(15)
target_tab_scroll.setWidgetResizable(True)
target_tab_content = QWidget()
target_tab_layout = QVBoxLayout(target_tab_content)
self._setup_target_tab(target_tab_layout)
target_tab_layout.addStretch()
target_tab_scroll.setWidget(target_tab_content)
self.left_tabs.addTab(target_tab_scroll, "目标卡")
```

### 设计决策

- **QGroupBox 标题分立**：拆分后「抽卡策略」和「目标卡」各自带 QGroupBox，不再用统一的「策略与目标卡」
- **方法命名**：`_setup_strategy_tab()` 保留原名（内容只是精简），`_setup_target_tab()` 新增
- **signal/slot 连接保持原位置**：`_on_strategy_type_changed` 连在 `_setup_strategy_tab()` 中，`_add_target_card` / `_remove_target_card` 连在 `_setup_target_tab()` 中，`cellChanged` 连在 `_setup_target_tab()` 中
- **`self.left_tabs` 索引不变**：新增 Tab 后索引顺延，但项目中没有硬编码的 `left_tabs.currentIndex()` 依赖
