# P80 出卡间隔分布可视化计划

> 日期：2026-09-13 | 状态：占位（设计待启动）| 优先级：中
> 背景：用户提出「出卡间隔的分布的分布」分析需求。现行全部统计把每条轨道压缩为一个数（GDR 随机变量），本计划研究把每条轨道压缩为一个「间隔分布」后的可视化。
> 前置调研：2026-08/09 完成方法学检索（§八）与真实数据稀疏性实测（§二），实测结论构成本计划的强制前提。

---

## 一、需求与目标

用户最终目的：通过对 N 条分布的可视化，让人能看出三件事：

1. **典型情况下的分布形态**
2. **极端情况下的分布形态**
3. **「我大概会有多少卡会是间隔多少出的」**（可读的数量结论）

## 二、核心前提：逐轨道分布不可辨识（已在真实数据上实测）

### 2.1 数据事实

真实配置 `gacha_simulator/config/config.toml`（策略 smart，6 张限定 SSR 目标，抽卡资源初始 55000），1000 条轨道，seed=42，`env.return_compact=True`：

| 指标 | 限定卡（6 张 limited_ssr） | 全部 SSR（12 张） |
|---|---|---|
| 每轨道抽数 | 均值 394.2，中位数 398 | 同 |
| 每轨道命中数 | 均值 4.6 | 均值 5.3 |
| **每轨道间隔数 m** | **均值 3.57** | **均值 4.31** |
| 池化间隔总数 | 3569 | 4308 |
| 间隔取值范围跨度 | 94 抽（约 10 个 10 抽箱） | 同 |

即：**每条轨道平均只有 3.6 到 4.3 个间隔点，去填充约 10 个箱。**

> **数据口径（2026-10-09 订正）**：以上数字用「缺陷 12 修复后」的引擎重跑（保底系统 bug：`infer_rarity_from_spec` 认不出 SR/R，软保底效果被打折，修复见 commit `68d42e3`）。修复前后的结构性结论完全一致，具体数值变动幅度见下方各表括注。修复前的旧数字来自已标记过期的缓存，不得再引用。

### 2.2 三层实测证据

**第一层，方差分解：轨道间差异的 84% 到 94% 是采样噪声。**

| | 限定卡 | 全部 SSR |
|---|---|---|
| 观测到的轨道间方差 | 73.1 抽² | 154.6 抽² |
| 预期的采样噪声方差 | 68.0 抽² | 131.6 抽² |
| 扣掉噪声后的真实方差 | 5.1 抽² | 23.0 抽² |
| 噪声占比 | 93.0% | 85.1% |
| 真实轨道间标准差 | 2.3 抽 | 4.8 抽 |
| 采样噪声标准差 | 8.3 抽 | 11.5 抽 |

（修复前同项为 93.7% / 84.6%，结论不变。）

**第二层，折半信度：轨道级统计量本身主要是噪声。**

| | 限定卡 | 全部 SSR |
|---|---|---|
| 折半信度（Spearman-Brown 校正） | 0.066 | 0.270 |
| 含义 | 观测轨道均值中真信号约 7% | 约 27% |

（修复前同项为 0.042 / 0.267，结论不变。）

**第三层，交叉验证：按「极端程度」排序分组的效果 95% 到 100% 是选择偏差。**

方法：把每条轨道的间隔对半拆（A/B），用 A 选组（最高/最低十分位），用 B 评估池化分布差异。选择偏差来自「用同一批数据既选组又评估」，交叉评估可将其切断。

| | 限定卡 | 全部 SSR |
|---|---|---|
| 同源评估（有偏）中位数之差 | 39.5 抽 | 58.0 抽 |
| **交叉评估（无偏）中位数之差** | **-1.0 抽** | **3.0 抽** |
| 零模型（随机分组） | 0.0 ± 0.4 抽 | 0.0 ± 0.7 抽 |
| 选择偏差贡献占比 | **103%** | **95%** |

（修复前同源项为 44.0 / 60.5 抽，结论不变。）

**措辞订正（2026-10-09）**：「选择偏差贡献占比」这一列把两件事混在了一起：**选择偏差**（用同一批数据既选组又评估会高估效应）与**衰减**（交叉验证用一半数据选组，选组变量本身噪声大，会低估效应）。真实效应落在有偏估计与无偏但衰减的估计之间，故该百分比偏大。**结论应由「可靠性只有 0.066 到 0.270」论证，不应由该百分比论证。**

结论：**在 3.5 到 4.3 个间隔/轨道的样本量下，无法可靠识别「真正极端」的轨道。** 按轨道自身统计量排序后展示的极端组，绝大部分是噪声排出来的。

### 2.3 本计划的前提（强制）

**单个样本轨道的间隔分布不可辨识，可辨识的是聚合分布。**

推论：任何以「单条轨道」为单位的分组、排序、聚类、距离计算（点云、降维、逐轨道中位数/离群检测、Wasserstein 距离矩阵）都不成立。设计必须先在可辨识的层级上聚合。

| 做法 | 是否成立 | 依据 |
|---|---|---|
| 池化直方图 + 分位带 | **成立** | 3569 个间隔池化后每箱约 350 个样本，稠密 |
| 粗分档山脊线（行数 5 到 15） | **成立** | 每行池化数十至数百条轨道，行内间隔数远超阈值 |
| 按「轨道自身间隔统计量」排序分组 | **不成立** | §2.2 第三层，95% 到 100% 选择偏差 |
| 逐轨道点云 / 降维 / 聚类 | **不成立** | §2.2 第一、二层，噪声主导 |
| 按可观测协变量分组（策略、池子、banner 等） | **成立** | 协变量直接观测，无估计噪声，无选择偏差 |

### 3.3 补充实测：轨道异质性判定与可用分档键探测（2026-09-13 新增，含三处勘误）

**理论层面**：单次模拟内所有轨道由同一配置、同一机制、不同随机种子生成，互为独立同分布（iid）实现。但这**不排除混合分布式的异质性**：从混合分布中 iid 抽样，样本仍然 iid，而总体可以是多峰的。若机制的路径依赖（早期运气决定后续资源充裕度与策略行为）使轨道落入不同 regime，则每条轨道自身的分布确实不同。

因此「轨道间是否存在异质性」是**经验问题，不是构造问题**，须逐配置实测。修正记录：本计划 2026-09-13 初稿曾写作「按构造不存在」，该表述过强，已更正。

**同质性诊断（实测）**：跨轨道经验 CDF 在固定 x 处的 5%~95% 带宽，实测与二项抽样噪声理论值 `2×1.645×√(F(1−F)/m)` 同量级（限定卡重算比值 0.55~1.14，均值 0.81），说明该带宽基本由抽样噪声构成，当前配置下未见轨道间真实结构。**注意：带宽基线是二项噪声，不是零**；`F=0.5, m=3.5` 时理论带宽已达 ±0.46，实践中在池化中位数处横跨 [0,1] 属正常现象。

**实证层面**：直接观测的轨道级变量探测（1000 轨道，seed=42）：

| 变量 | 唯一值数 | 变异系数 | 众数值占比 | 可否作分档键 |
|---|---|---|---|---|
| 总抽数 draws | 60 | 0.037 | 85.5% | 不可（85% 卡在上限 398） |
| 累计消耗 consumed | 60 | 0.037 | 85.5% | 不可（与 draws 同步，单抽成本恒 160） |
| 池子数 pools | 1 | 0 | 100% | 不可 |
| 等待次数 waits | 1 | 0 | 100% | 不可 |
| **限定卡命中数 lim** | 3 | 0.147 | 53.3% | 可用（4:533 5:365 6:102） |
| **SSR 命中数 ssr** | 7 | 0.202 | 35.9% | 可用（4:253 5:359 6:250 7:109 8:24 9:4 10:1） |
| 保底触发数 pity | 3 | 0.147 | 53.3% | 与 lim 完全相同 |

**关键结论**：单次运行内唯一有区分度的直接观测变量是**命中计数**，但用它分组近似同义反复（同抽数下命中越多则间隔必然越短），且条件于命中数会引入长度偏差（inspection paradox）。

**因此读法 B 的可行实现是跨配置对比**：策略、资源预算、保底配置、banner 结构等由用户设定、直接观测、无估计噪声的量作为分档键。此路径与项目既有的策略比较基础设施同构。

**原「一处未解释的偏差」已查清并结案（2026-10-09）**。原记录：限定卡的真实点云结构与打乱后无法区分（比值 1.019），SSR 组高于打乱后约 13 个标准差（比值 1.223）。修复缺陷 12 后重跑（限定卡 z = +7.5，比值 1.081；全部SSR z = +12.9，比值 1.219），并查明：

**该超额来自机制组成效应，不是 regime 异质性。**

1. **命中集语义不纯**。`全部SSR` 集合混了两类语义不同的命中：终止于限定卡的间隔（保底 `reset = "featured"` 会清零计数器）中位数 81 抽，终止于普通 SSR 的间隔（不清零）中位数 36 抽，中位数差 45 抽。解析验算吻合：普通 SSR 只能停在计数器 79 之前，其条件分布近似 [1, 79] 上的均匀，理论均值约 35 抽、占全部间隔的 13.55%，实测均值 37.3 抽、占比 13.9%。
2. **各轨道的混合比例不同**，故逐轨道间隔分布本身就不同。轨道平均间隔与「普通 SSR 命中数」相关 r = **-0.762**，r² = **0.580**（回归斜率 -11.24 抽/个）。分层均值单调：普通 SSR 命中 0/1/2/3/4 个时，轨道平均间隔为 76.7 / 62.0 / 53.4 / 46.9 / 40.3 抽。
3. **限定卡集合无此效应**：同一自变量下限定卡的 r = **+0.022**，r² = 0.000。限定卡每次命中都清零计数器，间隔是机制纯净的 iid 抽样。

**后果**：混合比本身是轨迹产出（普通 SSR 命中数），不是可事先观测的分组变量，故该结构**不能**用作山脊线分档键；§2.2 三层证据的结论（逐轨道不可辨识）不受影响。

**未做成的部分（如实记录）**：本轮尝试为「是否存在残余异质性」构造生成式零模型（按真实机制重抽更新过程），**未能校准**。零模型产出的每轨道间隔数均值高于真实（限定卡 3.64 对 3.57，SSR 4.68 对 4.31），原因是真实轨道受「6 张目标卡上限」与策略停止条件约束而零模型没有。z 分数随口径变号（限定卡 +2.2 与 -2.8 两个口径），**故本计划不采用该问题的任何 z 分数结论**。残余异质性即便存在，也被 §2.2 的信度数字（0.066 / 0.270）限死在不可用区间。

### 3.4 可辨识对象清单（2026-10-09 清点）

§2.3 的约束**只否决一件事**：以「轨道自身估出来的统计量」分组。间隔层面的一切池化统计、以及以**直接观测量**为条件的一切条件化，都成立。四个正交维度：

**维度一：单位**

| 单位 | 样本量（本配置） | 状态 |
|---|---|---|
| 间隔 | 3569 / 4308 | 已用（第一层） |
| 首次命中间隔 | 1000（每轨道恰好 1 个） | **本轮新登记**，见下 |
| 轨道（直接观测量） | 1000 | 已探测（§3.3） |
| 轨道（估计量） | 1000 | **禁用**（§2.3） |
| 保底规则 | 本配置 1 条 | §五.3 已裁决逐规则建命中集 |
| 配置 | 跨配置 | 读法 B（§四第二层） |

**维度二：条件变量（按可辨识性分三类，不可混为一谈）**

| 类别 | 例子 | 可用性 |
|---|---|---|
| 直接观测的配置量 | 策略、池子、资源预算、保底参数 | 可用：无估计噪声，无选择偏差 |
| 逐抽直接记录的状态量 | 计数器、池子归属、时刻、资源、终止卡类型 | 可用：无估计噪声 |
| 轨迹产出量 | 命中计数、是否触发保底 | 可用但须标注长度偏差与近似同义反复 |
| 轨道自身估出的统计量 | 轨道均值 / 中位数 / 形状 | **禁用** |

**维度三：统计量形态**

| 形态 | 状态 | 说明 |
|---|---|---|
| 密度 / 直方图 | 已用 | 第一层图 |
| 累积分布 | 已用 | 第一层图右列 |
| **风险函数 h(n) = P(出货 \| 已抽 n 未出)** | **未登记** | 保底机制的逐抽作用本体，可与配置意图逐抽对照 |
| **生存函数 S(n) = P(间隔 > n)** | **未登记** | 单调，稀疏下比密度稳健；直接回答「还要抽多少」 |
| 分位线 | 已用 | 第一层图 |
| 均值 / 方差 / CVaR | 可复用 | `core/distribution.py` 的 `EmpiricalDistribution` 已具备（间隔须 `use_evt=False`） |
| **分布间随机占优** | **未登记** | 项目已有 `comparison_analyzer`（PySDTest v2 Donald-Hsu），但只在 GDR 上用过，未在间隔分布上用过 |

**维度三两项未登记形态的可算性验证（2026-10-09 实测）**：

| 统计量 | 可用格点数 | 风险集下限（n ≤ 70） | 不可靠区间 |
|---|---|---|---|
| 生存函数 S(n) | 96（n = 0..95） | 2748（全部SSR）/ 3040（限定卡） | 无（超过最大间隔后恒为 0） |
| 风险函数 h(n) | 96 | 2572 / 3040 | 仅 n ≈ 88 至 90 共 8 个格点（风险集 < 30） |

实测形状（全部SSR）：S(40) = 0.776、S(70) = 0.638、S(79) = 0.597、S(85) = 0.044、S(90) = 0.000；h(80) = 0.1015、h(82) = 0.2674、h(85) = 0.5839、h(90) = 1.0000。软保底区间在两条曲线上都是清晰拐点。

**一条操作纪律（本轮实测得出）**：验证机制的基础出货率时用**首次命中的风险函数**（n = 1000，每轨道恰好一个独立观测），不要用池化间隔的风险函数（同一轨道的多个间隔不独立，设计效应使标准误被低估，本配置下同一处的估计相差 1.7 倍）。实测首次命中口径：P(首次命中 > 79) = 0.7220（全部SSR），解析值 0.996^79 = 0.7286；限定卡小 n 处 h ≈ 0.0023，基础率 0.002。

**维度四：对象数量**

| 形态 | 状态 |
|---|---|
| 单个池化分布 | 已用 |
| 条件分布 | 部分（§3.3 组成分析） |
| **分布之间的关系**（保底规则之间 / 配置之间 / 实测 vs 解析意图） | **未登记** |
| 联合分布（间隔 × 终止卡类型等） | 部分（§3.3） |

**本轮实测的两个新增可辨识对象：**

1. **首次命中间隔分布**：限定卡 n = 1000，均值 75.6，中位数 82，5%/95% = 22/86；全部SSR n = 1000，均值 69.8，中位数 82，5%/95% = 11/86。每条轨道**恰好贡献一个观测**，是唯一一个「逐轨道、由间隔派生、零选择偏差」的量（轨道均值受长度偏差影响，见 §3.3）。形状与池化分布一致（同一分布的另一组 iid 抽样），价值不在形状，而在它**可作为无偏的轨道级统计量**。
2. **第 k 次间隔**（按命中序号条件化）：k = 1 / 2 / 3 各有 n = 1000，均值 76.4 / 76.3 / 77.7，与 iid 一致；k ≥ 4 出现长度偏差（均值降到 70.2 / 60.7），只有运气好的轨道才走得到第 4、5 次命中。**k ≤ 3 可用，k ≥ 4 须标注选择偏差。**

**一个已查否的候选对象**：删失尾部（末次命中后到轨道结束的剩余抽数，当前被完全丢弃）。实测 n = 1000，均值 49.3，中位数 63，max 86，超过 90 的占 0%。但它是**确定性导出量**：尾部 = 总抽数 − 末次命中位置 − 1，两个输入都已观测，不含独立信息。分层看更清楚：限定命中 4 / 5 / 6 个的轨道，尾部中位数分别为 67 / 36 / 0（命中 6 个即集齐目标，全部立即停止）。**不予登记。**

**一条关于「菜单看起来很小」的判断**：本配置实测池子只有 1 种、等待只有 1 种（均 100%），故 §3.3 探测出「唯一有区分度的直接观测量是命中计数」。**这是配置贫瘠，不是方法贫瘠。** 换一个有池子轮换、资源生命周期、多条保底规则的配置，维度一与维度二的可用空间会立刻扩大。

## 四、方案（占位，待设计）

用户已裁决「两者都要」，故分两层：

**第一层（主，读法 A：中央与尾部，完全可辨识）**

1. **池化直方图 + 分位带**：全部间隔池化后画直方图，叠加 5%/50%/95% 分位线。回答「典型要等多久」「极端要等多久」「多大比例的卡落在哪个区间」。

   **示例图已产出**（2026-10-09，缺陷 12 修复后的真实数据）：`.recycle_bin/_pooled_hist_band_v2.png`，脚本 `.recycle_bin/_tmp_pooled_hist_v2.py`。四格布局：左列为池化直方图加分位线（含分位数角标框），右列为池化累积分布（直接读「多少比例的卡在多少抽内出」）。实测读数：限定卡 5%/50%/95% = 23/82/86 抽，全部 SSR = 9/81/85 抽；限定卡有 **84.1% 的间隔大于均值 75.5 抽**，证明均值在此分布上是低报的汇总（形状由软保底 `start=80, end=90` 决定，82% 到 83% 的间隔落在 80~90 抽）。图产物在 `.recycle_bin/`（已 gitignore），不入库。
2. **跨轨道分位带（降级为诊断，不进图表）**：逐轨道构造 CDF 网格，在每个 x 上对跨轨道值集取 5%/50%/95% 分位。**该带在当前配置下几乎完全由抽样噪声构成**（实测带宽 ≈ 二项理论带宽 `2×1.645×√(F(1−F)/m)`），不承载关于「典型/极端形态」的真实信息，故不作为展示图层。保留用途：每配置跑一次，比较实测带宽与二项理论带宽，判断该配置下是否存在轨道异质性（实测显著高于理论才提示存在 regime 结构）。

**第二层（辅，读法 B：跨配置对比）**

## 九、边界外延伸：把数据视为「序列」而非「分布」（2026-10-09 提出，已实测判据门）

**问题**：不把每条轨道压缩成一个间隔分布，而是保留间隔的**顺序**（序列），能否做某种聚类？

**信息论定位**：序列视角**严格**比分布视角携带更多信息。分布是序列在置换群下的不变量，即序列的一个摘要。故这不是两个并列方案，而是「序列 ⊃ 分布」。序列视角退化为分布视角，当且仅当**轨道内的顺序不携带信息**（间隔可交换）。

### 9.1 判据门（实测）

状态按「短间隔 < 80 抽」与「保底间隔 ≥ 80 抽」二分，转移计数单位为「相邻间隔对」。

| 命中集 | 相邻间隔对 | 滞后 1 自相关 | 和约束理论值 | 两状态似然比 G²（df=1） | 判定 |
|---|---|---|---|---|---|
| 限定卡（6 张） | 2569 | -0.2941 | -0.3893 | **0.01，p ≈ 0.941** | **无序列依赖，序列视角退化** |
| 全部SSR（12 张） | 3308 | -0.2023 | -0.3023 | **164.58，p < 0.001** | **存在序列依赖，序列视角不退化** |

限定卡实测转移计数 82 / 383 / 368 / 1736，与 iid 预期 81.5 / 383.5 / 368.5 / 1735.5 几乎完全吻合；全部SSR 实测 771 / 641 / 614 / 1282，对 iid 预期 591 / 821 / 794 / 1102，「短接短」与「保底接保底」被显著高估。

**机制解释**：序列依赖的**有无**完全由「命中集内的事件是否重置保底状态」决定，与 §3.3 结案条目是同一机制。
- 限定卡：每次命中都触发 `reset = "featured"` 清零计数器，每个间隔都从计数器 0 起步，间隔 iid，顺序无信息。
- 全部SSR：普通 SSR 出货**不清零**计数器，下一个间隔从计数器 c > 0 起步，天然更短。于是同类间隔相邻被高估。**注意此处的「序列结构」是计数器携带造成的，而计数器状态 `draw_pity_counter_max` 是逐抽直接记录的**，不需要靠聚类去反推。

### 9.2 方法学（已取得全文，附来源级别）

`Consistency of Optimal Matching-based Clustering for Mixtures of Markov Chains`（arXiv:2609.21985v1，2026-09-21，预印本，未经同行评审；本轮已取得全文并核对到数值实验节）。其记录的主导范式：**最优匹配（Optimal Matching, OM）距离 + 层次聚类或 K-medoids**；概率模型侧最常用的是马尔可夫链与隐马尔可夫模型。OM 是加权编辑距离，与 Levenshtein 距离同族，由生物信息学引入社会科学序列分析。

该文对本项目直接适用的两条约束：

1. **归一化 OM 距离的收敛率是 O(√(log n / n))，n 为序列长度**。序列越短，两条序列的 OM 距离越被有限长度涨落主导，而非被真实过程差异主导。
2. **聚类一致性依赖分离条件**「组内极限的**上确界** < 组间极限的**下确界**」。不满足时层次聚类与 PAM 均不保证恢复真实分组。

**代入本项目**：每条轨道的间隔序列长度 n ≈ 3.57（限定卡）/ 4.31（全部SSR）。该文数值实验中**最小的模拟长度是 n = 50**（此时平均 ARI 仅 0.6，尚不可靠），恢复到 ARI = 1 需 n ≈ 300（N = 800 条序列）；检验分离假设的一节用 n = 1000。本项目的 n 比其最小模拟长度还低一个数量级，**远在可恢复区间之外**。

### 9.3 结论

1. **逐轨道聚类序列不成立**，理由与 §2.3 同源且更强：可用信息量是「每条轨道约 3.5 个记号」，比逐轨道聚类分布还少，而串行依赖的辨认反而要求更多记号。
2. **序列视角在本配置下的真正产出是诊断，不是聚类**：它揭示了「全部SSR 的间隔分布不是良定义对象」（§3.3 结案条目、§五.3）。这个诊断只需转移矩阵，不需要聚类算法。
3. **总体层面的 regime 发现是另一回事，且可行**：混合马尔可夫链 / HMM 聚类池化全部轨道，本配置有 1000 × 约 3 ≈ 3000 个转移可供估计。但它回答的是「总体里有几个不同的转移核」，不是「哪条轨道属于哪一类」。本配置的保底只有计数器一个状态，且该状态已被 `draw_pity_counter_max` 逐抽记录，故此处预期只找到 K = 1。
4. **值得做序列聚类的场景**：机制的潜在状态**不可直接观测**，或多条路径依赖状态交叉。本项目中即 `rotating` 大小保底、`targeted` 定轨、`rotating_cr` 捕获明光三种保底类型，本配置一个都没用到。
5. **若推进，须单独立计划**（命名、面板归属、样本量门槛）。本节只登记判据门结果，不据以改动 §四 方案。
